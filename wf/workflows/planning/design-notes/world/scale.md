# design-notes／world／scale — 群像、地球尺度、勢力三層、各洲一把傘、大潮改讀、產能與時代（2026-10-24 晚）

來源同 [essence.md](essence.md)（talk-world 對談，原話在 `wf/workflows/dispatch/handoffs/talk-world/HANDOVER.md` 第 2 節）。第 1–6 段是**裁示級**；最後一段的數字是**數字級：提案，待使用者確認**，不是定案。

**群像，不指定臉孔。** talk-world 提議「指定四到六張會跨契約反覆出現的臉（Price／Makarov）」，使用者否決：「指定臉孔這件事，是太過依賴 MW 的後果。沒必要指定臉孔。地球上每個地方都有自己的傳奇，但如果要說整個地球的傳奇故事，那就是群像。」含意：傳奇的單位是「**某地某夜叫出一個名字**」——年表裡白夜、千面獨禱、九闕喪鐘、萬潮葬王那種；怪獸二名已是範例，人與勢力照寫。不寫全球主角，不設固定反派臉。

**格局放大到地球尺度；勢力分三層。** 使用者原話：「勢力很多，但是格局太小，就，感覺把整個地球當做是一個都市來看，不是這樣的，想想看現實世界的地球，七大洲八大洋，幾百個國家，八十億人，雖然現實世界地球的主角也就是那幾個國家，那幾個總統和名人，但把層級稍微降低，一大堆啊。」含意（talk-world 提、使用者未反對並接著談數字）：勢力分**全球級／洲級／地方級**三層；地方級用模板加種子生成，每個帶一條當地傳奇；局勢也分層——每洲每區各自一盤，全球級勢力偶爾把兩盤接起來；「鹽灘三約」是孟加拉灣那一盤的樣本，不是全球主線。現有 lore 勢力不刪，歸位成亞洲的洲級與孟加拉灣的地方級。

**怪獸入侵後人口大量損失。** 使用者原話：「當然，怪獸入侵後，人口損失很多，這很正常。」

**各洲一把傘。** talk-world 問殘聯是全球唯一的傘還是各洲各有聯盟，使用者原話：「各有一把傘。...去重新規劃數字吧，規劃數字就好。」含意：六把傘、各洲一把；殘聯的「31 城邦」改讀為**亞洲傘的創始／頂層 31 座**，不是地球總數。**殘聯歸哪把傘未定**：亞洲傘（奈洛比只是當年借的會場、非洲另立一把），或印度洋傘（南亞＋東非、西非另有一把）——lore 寫殘聯成立於奈洛比、城邦跨亞非，與「各洲一把」打架，待使用者定。

**大潮改讀為末日級；朔望叫漲潮。** 使用者原話：「全世界的機甲數量也是一個值得一提的數字」「機甲數量會隨時間愈來愈多，人類最擅長的就是爆產能。當然，怪獸也會爆產能。然後各種概念都可以更加多樣化，想想看，大潮來臨，那基本上是末日一般的景象，末日之後的世界局勢如何？後面怎麽推演？」talk-world 提：朔望只是「**漲潮**」（每月兩次、例行收成）；「**大潮**」是迫月撞朔望、重蝕這一級（每年兩三次量級，一洲一兩座城會不會失守的夜）；「**連珠潮**」幾十年一次（2089 那夜，滅一個區域文明）。使用者：「都對。」（頻率是 talk-world 抓的量級，使用者點頭。）含意：大潮是撞上迫月的那幾次漲潮——**每個大潮都是漲潮，反之不然**；原本「每月兩次的大潮日」一律改叫漲潮（日）；tide-sky 第四題「怒潮抬級」改成「**大潮抬級**」，潮候命名跟著改（見 [tide-sky](../tide-sky.md)）。

**人與獸都爆產能；世界有時代、無終點；大潮後重洗。** 原話同上段；talk-world 提人類年產每五年翻一倍、大潮後重洗五步（失守與露出 → 人動 → 債動 → 傘動 → 古代機動），使用者：「都對。」含意：兩條產能曲線（人類機甲、怪獸）各自上升，交叉就換一個「時代」；世界沒有終點；每次大潮後勢力版圖重洗。五步迴圈與「人贏則蝕線前推、獸贏則一洲一洲掉、月面成方舟」的推演是提案層的讀法，引擎上只多全球產能曲線＋「大潮後重洗」（見 engine-backlog）。
