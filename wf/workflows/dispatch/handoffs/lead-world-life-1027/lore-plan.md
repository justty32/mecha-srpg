# 地方人物、事件、勢力計畫

Ready categories：**characters、events、factions**，各六列，共十八概念，已完整落盤，可交主線審後分派 sol。交接表見 [lore-plan.json](lore-plan.json)；欄位沿用 plan.json。人物六檔、勢力六檔，事件六檔加 timeline 一檔，每批均少於二十檔。

沿朝鮮半島東南、安地斯、歐洲內海與山區補群像。人物不全走醒悟向善：崔恩率保票錢、朴度允扣布球、尼科拿偏手的環爭勝；其餘的職涯、教養與山路選擇也保留性格稜角。事件包含魚市人對人交火、古陵外探索傷損、地方主管背約扣人，以及失聯婚事、學術署名爭奪和失火後的住處爭執。勢力以地方獵團、朝聖短宿、種籽互存、山路引導與雙面戲班形成不同生計；既能合作，也會壓人、爭客和出賣同伴。

所有新 ID 使用 wl-。人物與勢力不引用本輪其他新批次，正文連結也只接既有資料；事件只有 timeline 指向本批新 event 的同批依賴。六個事件均在 2107 年、period=era/league，每列 concept.timeline_entry 已給完整內容；年表只插入六筆並保持排序，不改舊條目。這是地方記錄，不更動全球歷史錨點或既有外交關係。

每列 concept 是寫作指令，內部鍵（如 action_and_flaw、plot、timeline_entry、umbrella_context）不直接抄成 lore 新欄位。實際欄位遵守 content/lore/README.md；關聯欄用精確既有 ID，地方人物未建檔就只寫匿名職分。小勢力套範本的格式，不照搬大勢力規模、領袖、古代機與研發章節。

已讀沿用 [plan.md](plan.md) 記載的工作流、世界支柱、風格與地域裁示；本輪另讀／定向查詢 content/lore/eras 各檔的日期區間、六處既有 events 的日期與摘要、event/valparaiso-borrowed-stretcher 全文、korea-umbrella／latam-umbrella／euro-umbrella 的在地關係，以及 timeline 條目範本。各列 sources／template 留具體檔案，dedup 留名字與場景排除依據。阿瑪莉亞避開既有借山空返的露西亞稱呼；慶州人物不取代韓寶羅。
