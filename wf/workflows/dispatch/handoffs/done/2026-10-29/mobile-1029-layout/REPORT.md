# 手機布局實作

## 做了什麼

手機及短橫向改為自然單欄與可捲動內容；戰場及世界地圖提供固定可測高度、局部觸控手勢表面，營運標頭與資源換行，返回營運按鈕進入正常文流。手機及短橫向保留固定指令區並隱藏浮出選單，避免遮蓋地圖。依圖審修正短橫向指揮區高度與子項縮排，並讓桌面營運頂列完整顯示數值。百科側欄、搜尋及導航保持可達；快捷區依實作線提供的 class 設計為正常文流。

## 產出

修改 `src/ui-adapter/dom/style.css`、`src/ui-adapter/dom/shell.css`、`src/ui-adapter/dom/wiki/wiki.css`、`src/ui-adapter/ops/dom/ops.css`、`e2e/wiki.spec.ts`。百科 e2e 覆蓋 360／390／430 直向及 844×390，檢查分類展開與收合、控制高度、整頁無水平溢出。390×844 可透過 `MOBILE_SHOTS` 輸出百科截圖供圖審；`git diff --check` 通過。

## 證據不足

依交接禁止執行任何測試、npm、建置與瀏覽器；CSS 實際尺寸、側欄互動、其他頁主操作與視覺尚未驗證。建議領導串行執行既定 DOM／build 與有界四份 Playwright e2e，並做設計圖審。

## 需要決定

無；若瀏覽器測試揭露尺寸或遮擋問題，請領導回派明確失敗證據。
