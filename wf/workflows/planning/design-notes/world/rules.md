# design-notes／world／rules — 為何用機甲、十分律、基調、怪獸族

[world](../world.md)｜[design-notes 入口](../../design-notes.md)

## 2026-10-23 深夜：對規劃線第一版提案的推翻與補充

**為何 2108 還用機甲。** 就當作是古代遺跡給所有人洗腦了，並且世界規則也讓大家都喜歡機甲。最初是從古代遺跡中挖出機甲，並以此為藍本創造出機械機甲對抗怪獸。**古代遺跡與怪獸同時出現。** 含意：機甲中心主義是世界規則加上遺跡的影響，不需要物理藉口；機械系的技術譜系源自古代機甲（所以機械系能裝古代部件有脈絡）；遺跡與裂縫在時間線上是同一事件的兩面。

**推翻「相位說」。** 使用者：太糟糕。飛機與戰鬥機**也可以傷害怪獸，但傷害是十分之一，這是世界規則**。含意：不解釋為什麼，直接當規則寫；傳統兵器在戰鬥裡可以存在（空襲、砲擊）但效率十分之一，營運層可當昂貴的輔助火力。（**2026-10-24 晚已廢**：十分律改為「抵抗性」，見 [essence](essence.md)；本段原話保留作歷史。）

**怪獸多種多樣。** 有蟲族、獸族、異形、菌絲等。含意：怪獸的「族」是 body plan 與層組合的分類（蟲族外骨骼多節肢、獸族肉體厚、異形不對稱難預測、菌絲是地形化／擴散型的群體），捕捉成生物系機甲時各族走不同的拘束與駕駛艙方案。

**推翻「B 級是 C 級蛻變而來」。** 使用者：不要這個。含意：怪獸等級不是同一隻的成長階段；生物系機甲的養成另找規則（規劃／spec 線重提）。

**母體／子體與蛻皮：保留為某些族的設定，不是全體規則。** 母體繫子體（殺母體則子體斷繫）可以用在某類怪獸上；蛻皮（低階成長為高階）其實也可以，但只對某些族成立。含意：這兩種是族／個體資料上的可選行為（`spawner`／`molt` 類效果），不是怪獸等級制的通則。

**風格：太空歌劇，不要硬科幻（2026-10-24）。** 使用者原話：「我不太喜歡硬科幻，我想要的是太空歌劇類型，就，不要電磁學那套，想想 Warframe 那樣。」含意：整體基調轉向**太空歌劇**——科技帶神秘與奇幻色彩（古代文明遺產、半有機半機械、能量／源質類的超常力量、華麗的招式與宏大的勢力史詩），不以真實物理（電磁學、軌道力學、口徑與膛壓等）作為設定與命名的依據；名稱與描述偏氣勢與神話感，少工程術語。既有內容與 spec 中偏硬科幻的用語（如電磁砲、電弧、口徑 mm、熱量的物理解釋）之後要逐步改寫；數值機制（熱量、電能等資源池）可保留，但換成風格化的名字與解釋。 使用者補充：「就，不要太過現實啦。」

**十分律採擴讀（2026-10-24）。** 使用者原話：「十分律按照擴讀，反正大家都要用機甲！」含意：原話「飛機與戰鬥機傷害十分之一」擴大適用到所有傳統（非摹式／非古代／非生物）兵器——這正是大家都得用機甲的理由。現行 spec、numeric-bands 與 `conventional-arms` 標記的做法即為定案。（**2026-10-24 晚已廢**，同上。）
