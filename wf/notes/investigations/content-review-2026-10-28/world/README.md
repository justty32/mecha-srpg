# world 跨批增量審閱（2026-10-28）

## 問題

新七輪非人物內容與 bigfill 舊批是否重複、設定衝突，或只是同系列及正常配套？只交審閱文件，不修改內容。

## 方法

親自讀交接、適用規則、world-pillars 全部子檔、10/27 people/content 摘要與舊候選及 fill-rulings。以現行主樹原檔裁定；來源表舊 list 列經資料工具載入後在記憶體正規化，worktree 地址取 content 後綴映射 main，保留來源表及原列號。

入口已抽到 [entries.json](entries.json)（245 列）：舊批 181、新七輪 64。新七輪排除人物 18 後，為事件 6、勢力 18、地點 18、機甲 12、怪獸 10；第四輪全是人物，因此本線沒有該輪入口。配套不重算概念。共映射 287 檔（舊 181、新 106），缺檔 0。

[scan.json](scan.json) 記來源指紋、2,819 份 base/lore JSON 的機械解析、同類精確同名與 ID 檢索。漢字二字集合近似只排候選，另按地方用途、事件後果、血統、骨架、配裝及招式挑選全文對照；不把低分相似或相同數值直接當問題。

## 發現

[evidence.json](evidence.json) 有 16 組兩端全文對照：確認新問題 0、待裁決 0、已排除 16。每組附字段、實際行號、兩端 SHA-256、相似與差異、建議及信心；5 份機甲型錄與鹽紗兩份 frame 另作完整配套核讀。

W01 空冠社／穹頂住戶及 W02 換禮角／望鄉號是正常配套。W07–W09 跨第一、三、七輪機甲有骨架、掛件、勤務與事件差異，應保留同系列。W11–W14 怪獸有不同招式、池或採收限制，不能因共用骨架合併。W14 鹽紗互斥捕獲條件與只能採收的原文一致，來源工人報告亦明示為刻意限制，沒有重報為新 bug。

建議領導抽核 W07（斷纜／開扇，含型錄），可直接檢驗新跨批排除；另可抽 W01 或 W14。舊 P01、九槽缺口與 10/27 既有候選不重開。歷史修復識別以現存 b0a5ebef／8a577dcf 對應，未拿舊摘要當現行問題。

## 結論與限制

這 16 組未發現應合併或刪除的真重複，沒有新的使用者裁決項。這是有界候選審閱，不能推論全庫無問題或已完成遊戲驗收。

[coverage.json](coverage.json) 逐檔記讀取層級、指紋、入口歸屬與行數：292 檔中全文 48、僅機械索引 244。全文為新映射 39、舊入口 4、額外參照 5；其中新七輪主入口檔全文 28/64，配套仍有未讀。六份新事件已全文讀，但未各自遞移展開全部人物、年表與依賴。其餘地點／勢力及未選機甲怪獸維持機械層級，索引不等於全文。

未跑測試、lint、build、遊戲 check、sim 或平衡／取得流程驗證；怪獸變體的一招差異是否足夠影響實戰，仍待整合試玩。本線沒有內容改動、上網、下載、安裝、commit 或 push。
