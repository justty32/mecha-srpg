# style — 《潮獵》風格與用語（太空歌劇版，所有內容線照此寫）

[lore README](README.md)｜裁示原文 `wf/workflows/planning/design-notes/world.md`（2026-10-24 末段：「我不太喜歡硬科幻，我想要的是太空歌劇類型，不要電磁學那套，想想 Warframe 那樣」「就，不要太過現實啦」）

## 總綱

**不要太過現實。敢誇張、敢浪漫、敢中二。** 這個世界的規則靠「說了就是」撐住，不靠物理：十分律不解釋，殼訊不解釋，裂縫從哪來不解釋。寫設定與文本時的三條：

1. **意象優先於機制**。一把武器先有名字與畫面（「月弓一引，月壤如雨」），再有數字。數字只出現在型號迭代（II型、V4）與遊戲數值，不出現在世界觀敘述裡（沒有口徑、沒有瓦、沒有公里／秒）。
2. **古代遺產、半肉半鐵、超常力量、華麗招式、勢力史詩**——Warframe 的語感：東西是「長」出來的、「醒」過來的、「認」人的，不是「製造規格」。摹機也有一點神秘感：工程師看著殼「就懂了」，不是算出來的。
3. **冷硬潮濕的捕鯨船底色不丟**（見 world spec README 基調），但上面蓋一層神話的光：窮酸的獵團開著漏氣的老船，去拘束一隻會發光的怪獸，而船尾那門砲有自己的名字。黑色幽默與中二並存——角色自己也知道招式名很誇張，照樣吼出來。

## 能量與科技體系：核心名詞

一套取代「電／熱／電磁／彈藥」的風格化稱呼。遊戲資料的 pool id（`heat`、`charge`）不必改，**顯示名與所有敘述文字**用這套。

| 概念 | 本作用語 | 一句解釋（可直接寫進文本） |
|---|---|---|
| 一切能量的源頭 | **源潮** | 從裂縫另一端流過來的「潮」本身；殼、裂晶、異能都是它的不同凝態。先民叫它別的名字，刻痕沒翻出來。 |
| 怪獸的核／能源晶體 | **裂晶**（核） | 裂獸的心臟，一顆凝固的源潮。核碎即死；人類的一切能源從燒它開始。2108 最值錢的商品。 |
| 機甲的「電能」 | **流光** | 從裂晶抽出的光液，在機甲脈管裡流；流光池空了機甲就「暗」下去。充能叫**汲光**。 |
| 機甲的「熱量」 | **燼** | 流光燃過的殘渣，積在機甲骨架裡；積多了叫**燼滯**（動作遲緩）、再多就**燼爆**（部位自損）。散熱器叫**排燼**。 |
| 護盾 | **光幕** | 流光撐開的一層薄光，吃一下就散、過一回合又聚。 |
| 裝甲 | **殼甲** | 機甲的外殼；摹機的殼甲是摹殼（照古代殼的紋路鑄的），生物系是獸自己的礦甲，古代機是「殼」本身。 |
| 感測器／雷達 | **殼目** | 機甲「看」的器官；古代殼天生有，摹機是摹的。感測失準叫**目盲**。 |
| 子彈／炮彈／飛彈 | **矢** | 一切投射物統稱矢：**殼矢**（實體）、**光矢**（流光凝的）、**追矢**（會轉彎）、**拘束矢**（捕獸用）。不講口徑，講「幾矢連吼」。 |
| 槍／砲 | **吼砲**／**連吼** | 砲叫吼砲，速射的叫連吼；名字按「意象＋器類」：「雷雞連吼」「斷崖吼砲」。 |
| 電弧／能量放射 | **弧光** | 流光直接潑出去的樣子，不是電。「弧光矛」「裂光斬」。 |
| 近戰刃 | **潮刃**／**殼刃** | 以流光鍛的叫潮刃，以獸甲削的叫殼刃。 |
| AI | **機魂** | 住在**魂核**裡的另一個駕駛員（world spec 既有）。沒登錄的叫**野魂**。 |
| 電腦／運算 | **算核**／**算力** | 機魂思考用的東西；「算力池」是機魂的資源（既有）。 |
| 程式／軟體 | **術式** | 寫給算核跑的東西叫術式；科研「開節點」是刻新術式。 |
| 衛星／通訊網 | **星哨**／**天網** | 軌道上還活著的哨站叫星哨，它們撒下來的訊息網叫天網。 |
| 飛艇／浮船動力 | **浮芯** | 一環裂晶撐著船浮在潮上；老船還混用氣囊，所以會「漏氣」——窮酸是質感，允許。 |
| 塞勒涅的質量驅動器 | **月弓** | 把月壤射向地球的那座東西；民間叫它月弓，塞勒涅自己叫型錄編號。 |
| 地月渡輪 | **渡潮船**／渡輪 | 弦月開船、三天到月。 |
| 舊世界的飛機／戰機 | **鐵翼** | 十分律之下只值十分之一的東西；殘翼航空的「殘翼」由此來。坦克叫**鐵龜**。 |
| 古代機甲的能力 | **異能**（殼技） | 一台一種，不走部件（既有）。招式名要中二：「不退之誓」「殼矛」「假繫」。 |
| 先民 | **先民**／前潮文明 | 一萬一千年前走到生物系終點的人（既有）。 |
| 遺跡／裂縫／另一端 | **殼**／**潮**／**裏側** | 獵團黑話（既有）。 |
| 科研 | **鍛研** | 技師與學者把裂晶、刻痕、屍體變成部件與術式的過程；「開源」叫**公刻**（把圖刻在天網上誰都能摹）。 |

## 武器與招式的命名語感

- **武器**＝意象詞＋器類：「斷崖吼砲」「雷雞連吼」「弧光矛」「千囊轟」。不帶數字口徑；迭代用型號（「斷崖吼砲-II」）。
- **摹機系列**照 design-notes 三階：D 級代號（「犁」「K-9」）→ A–C 級系列＋型號（「堅盾-II型」「長槍-V4」「燕鷗」）→ 高階愈中二（「幽冥鐵騎-浮屠」「極光」「白夜」），隊長機用「冠名-系列」（「連星-劍魚」）。系列名偏器物、鳥獸、神話；勢力各有一套語感（塞勒涅型錄體＋希臘神話、殘聯軍械庫鳥名、釜山佛教語、基多安地斯神名…）。
- **古代機**原始無名，由發現者以神話命名（既有）：夸父、刑天、恩底彌翁、維拉科查、處容、迦梨、恩凱、埃吉爾、赫卡忒……不同勢力可叫同一台不同名。
- **招式**：古代異能四到六字、像誓言或咒（「不退之誓」「借傷萬年」）；生物系吼出來的是承擔（「牠先吃我！」）；機魂的招式名由機魂自己取，可以很怪（「請確認償還意願」是手套的催收起手式）。
- **稱號**：A 級以上怪獸有二名（「千囊房東」「赤眼兇星」「白夜」），生物系機甲有登記號／小名／凶名（既有）。

## 禁用詞（敘述文本與命名裡不出現；遊戲資料 id 不受限）

電磁、電壓、電流、電池、伏特、瓦、焦耳、千瓦、電子、電路、晶片、電腦、程式碼、演算法、量子、奈米、核融合、核分裂、反應爐、口徑、毫米／公厘／mm、彈道學、軌道力學、推進劑、火箭燃料、Δv、公里／秒、雷達、聲納、衛星（→星哨）、無線電（→天網）、飛彈（→追矢）、砲彈／子彈（→矢）、坦克（→鐵龜）、戰鬥機（→鐵翼）、電能（→流光）、熱量（→燼）、電弧（→弧光）、散熱（→排燼）。

允許保留：氦／氣囊（老船的窮酸）、地熱（城邦的牆內日常）、「論文」（學界存在，但沒有結論——那四千篇十分律論文是個笑話）。

## 寫人物與勢力時

- 勢力要有史詩：一台藍本古代機、一條研發血統、一場代表性戰役、一次背盟或結盟。
- 機魂的個性是**後期、稀有**的現象：一般機魂照本宣科、沒有鮮明人格；只有 S 級以上（節點開滿、陪伴夠久、或出了事）的機魂才長出口頭禪、怪癖、對某個人的執念——會給招式取名、會記仇、會想回家。lore 裡的傳奇機魂都是這種罕見存在，寫它們時要點明「這很罕見」。
- 怪獸是天氣也是神話：寫牠的二名怎麼來的，而不是寫牠多重。
- 駕駛員會死，死得平淡；但吼出來的那一回合要寫得像歌劇。
