# opening — 開場敘事樣稿

[world/README](README.md)｜裁示原文 [design-notes](../../design-notes.md)

**使用者裁示**：網頁、無美術；介面走一般網頁遊戲元件＋快捷鍵（2026-10-24）；敘事文本的深度隨意。

**我的提案**：基調是冷硬、潮濕、帶黑色幽默，上面蓋一層太空歌劇的光（`content/lore/style.md`），留著機器人動畫的熱血橋段——意志、吼聲、超限的一回合（使用者 2026-10-23 補充裁示）；敘述用第二人稱現在式，對白短，不解釋世界觀——讓名詞自己出現。第二版校對：副腦改機魂、達卡的巢改成寬度 C 的蟲族裂縫、戰場樣例移到有了生物系之後。2026-10-24 校對：開局三台對齊實作 `campaign-start/default.json` 與 lore（兩台犁改燕鷗攻堅型＋一台拼裝獵犬-II型，皆 C 級）；裂縫第四天＝上個大潮開的，所以下個大潮在十一天後（第 15 天），不是三天後。下面是開場約九百字＋兩段樣例（營運畫面、戰場記錄）。

**理由**：文字遊戲的第一分鐘決定玩家信不信這個世界，與其介紹設定不如讓他先欠一筆債。

**放棄的替代案**：史詩開場（第一次蝕潮的全球災難蒙太奇）——氣派，但與「傭兵的這個月」的尺度不合，也會讓後面每一句都顯得小。

## 樣稿：葬禮

老桂的葬禮沒有棺材。浮船上不留重的東西，所以你們把他捲進機庫的防火毯，從候鳥號的貨艙口推出去，讓他掉進雲底下的野地。鐵姨說這樣至少會有東西吃他，比留在城邦的冷櫃裡等人付火葬費體面。

沒有人反對。船上剩五個駕駛員、一個技師、一個廚子兼醫官，再加上你——老桂的副手，從今天起是團長。這個頭銜連同一艘漏氦的飛艇、三台 C 級衍型機、一個租來還沒練熟的機魂、半艙生鏽的零件，和一筆你還沒看到數字的債，一起傳給了你。

債主比你先看到數字。葬禮結束不到十分鐘，艦橋的終端就亮了：塞勒涅工業，地月信貸部，一個很有禮貌的女聲。她說節哀，說合約第十四條讓她有義務在債務人變更後七十二小時內確認新債務人的「償還意願」，說她不急。然後她報了數字。你發現自己在算這艘船拆掉賣能值多少。答案是不夠。

「下一次大潮十一天後。」鐵姨在你背後說，不是安慰，是提醒。「孟加拉灣那條蝕線上個大潮往北推了兩塊，殘聯昨天掛了契約：達卡北郊，一道寬度 C 的蟲族裂縫，上個大潮開的，今天第四天，巢母剛坐下——再過一個大潮牠就開始吃地。清掉，收復金另算。老桂本來要接的。」

「他接了嗎？」

「他死了。」鐵姨聳肩。「所以沒有。」

你走去機庫。三台衍型機站在固定架上，像三件掛太久的舊外套：兩台是殘聯淘汰的「犁」式工程機改成的燕鷗攻堅型，船上還是叫它們犁一、犁二；一台是老桂當年從別的獵團屍體上拆回來拼的獵犬-II型，左臂比右臂短一截。犁二的胸口亮著一顆租來的魂核，沒人跟它說話。阿九蹲在拼裝機旁邊，手貼在它的鎧甲上，像在聽心跳。那是他的習慣，雖然這台東西沒有心跳。阿九的獸緣是全團最高的，意志也是——達卡蝕線往北推的那兩塊，有一塊是他長大的地方。老桂一直想弄一台生物系給他，說那孩子天生就該騎活的東西，「他有東西要扛」。老桂現在在雲底下，而拘束艙還是空的。

「團長。」阿九站起來，試了一下這個詞的重量。「我們去達卡嗎？」

你看著他。寬度 C 的裂縫，意思是巢母大概兩層樓高、囊口兩個，子體十幾隻，大潮那天會翻倍。殘聯的契約金付得起這個月的薪水和一半的債息。如果你們能活捉一隻子體——只要一隻鐮肢——拘束艙就不空了。

「鐵姨，」你說，「拘束矢還剩幾發？」

「四發。兩發過期。」

「過期的也裝上。」

窗外，月亮正在變圓。
