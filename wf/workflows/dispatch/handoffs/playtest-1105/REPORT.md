# playtest-1105 試玩報告

## 總評

能完整遊玩：3 場手打戰鬥、1 次戰役出擊與結算，全程無崩潰、卡死或非法狀態；10/28 新機甲、怪獸形態、人物都實際上場，新招式也被 AI 使用。
最大問題在數值與 AI：敵方命中幾乎恆為 100%、鐮肢過強，AI 又常原地挨打或放棄守區，勝負很看玩家是否發現這些漏洞。
資訊與文案瑕疵多（英文 id、新形態無顯示名、死亡敵人殘留、MCP 地圖在 structured 輸出看不到），不擋遊玩，但很傷新玩家理解。

場次（原始紀錄見 [raw-notes.md](raw-notes.md)）：exm-crossline s11 手打敗（R10 全滅）；exk-four-corners s7 手打勝（hold，R17）；exp-four-choices s3 手打勝（repelled，R9，0 損）；戰役 seed 5 出擊勝（R3）。auto 對照：crossline s11 我方勝、four-choices s3 敵勝；campaign_auto s5 greedy 跑 3 蝕月。

## 錯誤

1. **已陣亡的敵人仍留在 units 列表**：標 stale 並帶血量%，有時與我方單位同格。重現：exk-four-corners s7，R9 擊殺鹽針，R12 observe 仍列在 (29,30)，與我方生物鐮肢同格；exp-four-choices s3 的兩隻蝕蟲亦同。我方被擊毀的機在 brief 只顯示 hpPercent 66–78%，沒有「已擊毀」標記。
2. **士氣效果名顯示英文 id**：事件寫「受到「shaken」/「breaking」/「fleeing」影響」；`effects/morale-shaken.json` 的 name 就是 "shaken"，同類效果應該也一樣。重現：exm-crossline s11，R5 IX-12 被擊毀時。
3. **MCP 地圖看不到**：`battle_observe map:true` 的 ASCII 圖只放在 text content，structured JSON 刻意拿掉 ascii（`src/mcp/battle-hub.ts:54`）。只讀 structuredContent 的 client（本次即是）完全看不到地形，只能自己去讀 map 檔。
4. **戰役開場劇情順序倒置**：day 0 可以先出擊打完一場，第一次 advance 才跳出老桂葬禮與債主來電。重現：campaign_new seed 5 → sortie_begin → finish → advance 30（停在 day 1）。
5. **拆屍沒有回饋**：選「拆」後只有「一筆計畫外的帳落了下來。」，cash 與 stock 都沒變，看不出拿到什麼。重現：同上戰役，出擊後處理曲針屍體。

## 手感／平衡

1. **命中不對稱**：AI 攻擊幾乎都是 100%（鐮肢劈斬帶著晃眼 -8 也照樣 100%）。我方近戰 36–49%，遠程打單位卻都 100%，連射程 6 也一樣。減命中 debuff 與近戰因此很雞肋；打部位只有 3–36%，幾乎沒人會選。
2. **鐮肢（reaper-c）過強**：劈斬 2 AP、pierce 40，一回合三刀、每刀約 28，被縛網也照樣移動連砍。exm-crossline s11 一隻鐮肢殺光四台試配機；同 seed 的 battle_auto 卻是我方勝，差別在 AI 會用「武器招架」（DefensePrepared 16 次），但玩家從介面看不出招架的價值。
3. **AI 太被動、收尾突兀**：
   - exp-four-choices s3：R3–R6 四隻敵人站在 7 格外不動，被紋刻一吼狙死兩隻。
   - exk-four-corners：敵方勝利條件是撐過 R20，AI 卻在 R10 後全員離開守區，讓我方空守 8 輪即勝。
   - 滿血鐮肢從我方部署邊撤出，就直接判 repelled 勝利。
4. **燕鷗攻堅型「裂晶弧光」太強**：2 AP、射程 6、thermal 21、100% 命中，一回合可放 3–4 發；戰役首戰 R3 無傷，讓其他選擇失去意義。
5. **exk-four-corners 部署**：player-0（燕鷗）出生在 (16–21,23–28) 殘牆圍成的房間內，只有 (19,28) 一個瓦礫缺口，前兩輪幾乎動不了。
6. **盾甲**：約 950 HP，多數回合只重複放自 buff「王蓋高擎」，打起來只是消耗時間。
7. **戰役經濟**：campaign_auto s5 greedy 第 1 月現金從 1200 跳到 26080，之後每月只 +1k；債 24000 三個月都沒還，即使現金已超過債額。

## 文案

1. **新怪獸形態沒有顯示名**：brief 寫倒鉤／鎖翅／燼吻／背針，戰場上只顯示物種名鹽針／燈腹／掘犬／棧背；`monster/exk-*.json` 沒有 name 欄位，玩家無法對應。
2. **情境 brief**：
   - cx3-flyingfish-shoal 開頭是英文「Flyingfish Shoal。」。
   - combined-arms-battlefield 混入開發者語「尚無實體尺寸碰撞規則」，且敵方實為白手套卻寫「敵方蝕蟲」。
   - exk-split-roots 尾段像配裝備註。
   - exp-four-choices 與 exp-unfinished-ties 的 brief 一字不差。
3. **說明與用語**：
   - legal_actions 中「武器招架」的 does 是空字串。
   - 「地物受到 21 點傷害」不說是哪個地物，每發還重複三行。
   - 結算用「第 3 回合」，戰鬥中一律用「輪」。
   - 戰役選單露出開發用字「ops 尚不支援此品項交易」，label 直接印「材料 {}」原始 JSON。
4. **戰役 log**：day 0 一次噴 140 行「天網收到裂獸群 75的行動訊號。」（數字後缺空格）；數值帶浮點尾數（str 27.549999999999997、cash 27079.004000000026）。
5. **人名格式不一**：新人物顯示為莉妲、奧瑪、葉榛（只有名），宮坂 岳卻是全名；舊角色如瑪拉・奧可耶也是全名。

## 玩家感受

**好玩**：部位分層的傷害回報很具體，打斷翼、斷肢出血、失血死亡都有戲；一線穿刺、縛網、招架反擊這些戰術選擇有手感；新形態的弱點真的會改變打法；戰役的債務開場與契約板有吸引力。

**不好玩**：沒有地圖時只能盲走，一直被回「不可達」；AI 時強時呆，勝負常取決於有沒有發現「站遠狙擊」或「等牠撤退」；英文狀態名與空白說明讓人不知道該用什麼；戰役每一步的輸出都很長，用 MCP 玩起來很累。
