# world-pillars／world — 基調、鐵律、舞台、獵團與勢力、沙盒與大地圖、怪獸族（W1–W9）

### W1 太空歌劇，不要硬科幻，不要太過現實，敢中二

**為什麼**：「我不太喜歡硬科幻，我想要的是太空歌劇類型，就，不要電磁學那套，想想 Warframe 那樣」「就，不要太過現實啦」。
**做**：意象先於機制——先有名字與畫面再有數字；科技帶神秘與奇幻色彩（古代遺產、半肉半鐵、源潮／流光／燼這類超常力量、華麗招式、勢力史詩）；東西是「長」出來、「醒」過來、「認」人的；角色知道招式名很誇張照樣吼。冷硬潮濕的捕鯨船底色不丟，神話的光蓋在上面。
**不做**：禁用詞（電磁、口徑、mm、瓦、雷達、衛星、量子…照 style.md 換詞）；用真實物理解釋設定；數字進敘述；寫成純搞笑或純寫實軍武。
→ [world「風格：太空歌劇，不要硬科幻」](../../planning/design-notes/world.md#2026-10-23-深夜對規劃線第一版提案的推翻與補充)

### W2 兩條世界鐵律不解釋：十分律與「人類就是喜歡機甲」

**為什麼**：「飛機與戰鬥機也可以傷害怪獸，但傷害是十分之一，這是世界規則」；為何 2108 還用機甲——「就當作是古代遺跡給所有人洗腦了，並且世界規則也讓大家都喜歡機甲」。
**做**：傳統兵器可以存在（鐵翼空襲、鐵龜、船尾吼砲）但對獸只值一成，當昂貴的輔助火力；凡兵 tag、怪獸 tag `kaiju` 照 numeric-bands；機甲中心主義當作世界常識寫，不找藉口。
**不做**：給十分律補科學解釋；寫出不吃十分律的傳統兵器；「相位說」（裂獸半在另一相位）已被推翻（「太糟糕」），不要再出現。
→ [world「為何 2108 還用機甲」「推翻相位說」](../../planning/design-notes/world.md#2026-10-23-深夜對規劃線第一版提案的推翻與補充)

### W3 2108 地月舞台；遺跡與怪獸同一夜出現；機械系的源頭是古代機

**為什麼**：「預估時間線 2108 年；戰場是地球＋月球」「最初是從古代遺跡中挖出機甲，並以此為藍本創造出機械機甲對抗怪獸。古代遺跡與怪獸同時出現」。
**做**：地球為主、月球為次（遺跡大多在地球、有些在月球；怪獸主要在地球）；年表錨點（2089-03-14 第一次潮、2089-05 夸父認主、2091 摹一…見 lore-text）不動；摹機能嫁接古代部件有這條脈絡。
**不做**：人類在潮之前就有機甲；遺跡早於裂縫千年才被挖出；把月球寫成主戰場。
→ [world「時代與舞台」](../../planning/design-notes/world.md#2026-10-23-世界觀裁示第一版)、[「為何 2108 還用機甲」](../../planning/design-notes/world.md#2026-10-23-深夜對規劃線第一版提案的推翻與補充)

### W4 獵團＝自營傭兵；勢力自己打仗，傭兵去參戰、享補給

**為什麼**：「玩家是獵團，也就是偏向於自營傭兵的感覺。實際上各勢力自己會組織部隊去清剿／攻堅等……像這種傭兵就可以參戰，到時候合作，並且還可以享受到勢力的補給。」
**做**：勢力在世界圖上持續發動作戰（清剿、攻堅、圍堵、護航），不等玩家；契約除「發包單幹」還有**參戰型**（盟軍 slot、勢力 AI 指揮、補給：彈藥維修醫療甚至借機）；勢力 lore 必有「對傭兵：態度與補給」節。
**不做**：勢力只會發包、沒有自己的部隊；玩家是唯一能打怪的救世主；拯救世界的英雄敘事——只有這個月的薪水與債息。
→ [world「獵團＝自營傭兵」](../../planning/design-notes/world.md#2026-10-23-深夜對規劃線第一版提案的推翻與補充)

### W5 勢力大大小小很多；勢力間有外交，也會衝突

**為什麼**：「勢力可以大大小小，很多」（推翻「六個勢力」）；「勢力之間也可能有衝突」「勢力與勢力之間會有外交關係」。
**做**：城邦、公司、教派、小獵團都是勢力；`relations` 同盟／友好／中立／緊張／敵對反映 2108 當下，變化寫成事件（背盟、結盟）；勢力間交火是作戰類型之一，傭兵可被雙方雇用、選邊有聲望後果；人類機甲敵人（白手套、競爭獵團）存在。
**不做**：只有六大勢力各一章；勢力只共同對抗裂獸、永不互打；關係寫死永恆不變。
→ [world「勢力可以大大小小」「勢力間衝突與外交」](../../planning/design-notes/world.md#2026-10-23-深夜對規劃線第一版提案的推翻與補充)

### W6 沙盒：開著船去自己想去的地方；世界自己在動

**為什麼**：「希望這是沙盒遊戲：玩家可以開著飛船去自己想去的地方。」
**做**：契約與事件是地圖上可選的機會；壓力來自世界自己在動——潮月節拍、裂縫占領地盤並衍生子體、勢力消長與作戰；地點（城邦、蝕域、遺跡、裂縫、月面港）可自由前往。
**不做**：強制主線、關卡順序；「先完成 X 才能去 Y」的劇情鎖（地理與外交封鎖可以，劇情閘門不可以）；劇情推進才讓世界變化。
→ [world「沙盒」](../../planning/design-notes/world.md#2026-10-23-世界觀裁示第一版)

### W7 大地圖是方格、自由行動；每大洲一張

**為什麼**：「我會希望可以在大地圖上自由行動，也就是大地圖本身也是方格式」「可以每大洲一張地圖」。
**做**：地點有 `continent`、位置是格；船在格上移動、時間隨移動流逝；勢力部隊、商隊、裂獸群、別的獵團是會動的東西，野外可遭遇、追擊、迴避；洲際以航道／渡潮船切換。
**不做**：節點＋航線的選單式描述（「從 A 節點走路線到 B」）；把大地圖寫成戰場格子（共用渲染不共用狀態）。
→ [world「大地圖方格化、自由行動」](../../planning/design-notes/world.md#2026-10-23-深夜對規劃線第一版提案的推翻與補充)

### W8 怪獸多族；等級不是成長階段；母體子體與蛻皮只限某些族

**為什麼**：「怪獸多種多樣。有蟲族、獸族、異形、菌絲等」；「B 級是 C 級蛻變而來——不要這個」；母體／子體與蛻皮「保留為某些族的設定，不是全體規則」。
**做**：族＝body plan 與層組合（蟲外骨骼多節肢、獸肉厚、異形不對稱、菌絲地形化）；不同級是不同 species；`spawner`（蟲族巢母）、`molt`（獸族）做族別資料；怪獸是會擴張的勢力（裂縫→占領→子體）。
**不做**：寫 C 怪長大變 B；每族都有母體或都會蛻皮；怪獸只是刷新的敵人、沒有地盤。
→ [world「怪獸多種多樣」「推翻 B 級蛻變」「母體／子體與蛻皮」](../../planning/design-notes/world.md#2026-10-23-深夜對規劃線第一版提案的推翻與補充)

### W9 等級 SSS–D 共用一條尺；SS／SSS 先不設計

**為什麼**：「機甲等級與怪獸等級都是 SSS 到 D；SSS 是最終 boss；SS 是王下四天王，有五個」「SS／SSS 先不要設計，先從普通怪獸開始設計」。
**做**：內容寫 D–A；S 只寫定位（每個大型蝕域一隻、人取名「XX 的那隻」）；留「潮壓有源頭」一句當接口。
**不做**：自行發明四天王名單、最終 boss、SS 級機甲或機魂；把 S 寫成可量產。
→ [world「等級」](../../planning/design-notes/world.md#2026-10-23-世界觀裁示第一版)
