# time-and-tick — 潮月 28 天、每日結算順序、大潮與弦月、時間推進政策

[ops README](README.md)｜世界觀來源 [world/rifts-and-territory](../world/rifts-and-territory.md)、[world/operations](../world/operations.md)｜裂縫狀態機在 [data-model-world-map](data-model-world-map.md)

裁示：一局時長不限；營運層一天一 tick、二十八天一潮月、第 1 與 15 天大潮、第 7 與 21 天弦月、一場戰鬥不占營運時間、認主只在大潮之夜（world 暫定裁示）。BB 的日結順序問題（OPS-02／DAT-12／DAT-13）在此用「先算全團、再按政策分配、跳轉逐日補算」回答。

## 曆 Calendar

```ts
type Clock = { day: number /*自開局起 0..*/; month: number /*floor(day/28)*/; dom: number /*1..28*/;
  phase: "spring" | "neap" | "ordinary" };            // spring＝大潮（dom 1、15）、neap＝弦月（dom 7、21）
```

曆是純函式 `clock(day)`；內容包 `calendar.json` 可改週期與特殊日（例：月面「背面裂開紀念日」事件），程式不寫死 28。**時間只由玩家推進**：`等 N`、航行、探勘、渡輪都換算成 N 個 `tick()`；離線時世界靜止（單機回合制，OPS-20 的答案）。戰鬥發生在某一天之內，結束後當天繼續，不耗 tick。

## 一個 tick 的結算順序（固定、可測）

每個 `tick()` 依序跑八段，每段是 `(state) → (state', CampaignEvent[])`，段內再按 id 字典序迭代以保決定性：

1. **曆與旗標**：`day++`、算 `phase`；大潮日開 `anchorable` 旗。
2. **世界**：裂縫狀態機與新裂縫（大潮日）、潮壓、蝕域深度；勢力行動牌（每天）。
3. **移動**：船／渡輪／徒步 `daysLeft−−`；到達；淺蝕節點擲遭遇。
4. **事件**：節點／路線／船上事件抽牌；有待選者 tick **暫停**。
5. **船務**：工時灌佇列；獸欄；陪伴；醫務；燃料與船體。
6. **帳本**：薪水、飼料、泊費、租金、利息；所有 `post` 集中於此。
7. **契約與市場**：到期；弦月刷新；渡輪開船；rep 回歸。
8. **摘要**：`DaySummary` 事件。

細則：第 2 段大潮日才轉裂縫狀態、才抽新裂縫，行動牌天天抽；第 3 段途經淺蝕節點的遭遇寫成 `pendingBattle`，玩家可付燃料撤退；第 4 段事件是 BB 式兩三個選項，寫入 `pendingChoices`，等玩家選完才續後段；第 5 段依序跑工時產出與四條佇列、獸欄餵食／馴化／hunger／族行為日程、陪伴時段（mastery、trust）、醫務（hp 回復、傷勢時鐘 −1）、燃料與船體維護；第 6 段先算全團應付薪水再等比例付或欠，大潮第 1 天把利息入 `debt`，失敗政策只在這一段明示；第 7 段到期契約轉 `expired`／`failed`，弦月刷新市場與招募池、判定渡輪開船，勢力 rep 朝 0 每潮月回歸 1 點；第 8 段的 `DaySummary` 是錢、人、獸、裂縫四行，text 層只讀它組「今日」訊息。

跨多日（`等 7`）**逐日執行全部八段**，不合併（DAT-13 答案：補算每個結算點）。段 4 暫停時，剩餘天數保留在 `pendingTicks`，選完自動續跑。

## 航行與潮月

航行只是「連續 N 個 tick 且船在路線上」：`航 <節點>` 把路徑換成 `ship.route`，每個 tick 第 3 段推進一天，途中每天照常跑八段（事件、佇列、帳本都在走）。所以航程是用時間買距離：橫跨一洲約一潮月的量級，趕下個大潮封新裂縫要算天數，弦月要人在赤道港才搭得上渡輪。玩家隨時可 `航` 到別處改道（路徑從當前位置重算），或 `泊` 在任一節點等；沒有任何節點要求先完成什麼才能去——沙盒的自由由路線、燃料與深蝕三件事約束，不由關卡。

## 大潮日的特別事項

大潮日段 2 會：(a) 每個 `anchored` 裂縫蝕化鄰節點、`anchorAge++`；(b) `unanchored` 無守軍 → 回 `anchored`、`fedCount++`（養裂）；有守軍（玩家接了 `seal` 契約並在當天勝）→ `sealing`；(c) `sealing` 守第二次 → `sealed`；(d) 以潮壓抽新裂縫；(e) 大潮之夜：`dormant` 殼可被 `喚`；蟲族 `brood`；蟲族裂縫子體出巢（野地事件表切換成「大潮版」兩天）。所以大潮當天出門是收成也是災難，前一天是備戰。弦月：渡輪開船、市場與招募刷新、世界最安靜（事件表凶險檔 −1）。

## 長程時鐘的量級（寫在內容包，這裡只給尺）

馴化 C 數天、B 一兩週、A 一潮月；修一層裝甲一天量級、重建一個部位一週量級；暫時傷 1–3 潮月；永久傷不癒；獸族蛻皮窗口約一潮月、異形每潮月第 1 天變異、蟲族每大潮一批；育魂一潮月起、練熟一個節點約一週的時段；認主只在大潮之夜；渡輪單程 3 天、弦月開船；利息每潮月。所有數字都是 `NumExpr` 或模板欄位，可被內容包改。

## 終局

沒有勝利終點（SS／SSS 待裁示）。結束條件兩個：名冊上駕駛員（含可獨駕的機魂）為零、或 `cash` 低於 `−(debt×k)` 且塞勒涅催收事件鏈走到底（船被扣押）。兩者都寫 `CampaignEnd` 事件，存檔保留可讀。

## 替使用者做掉的決定

1. **時間只由玩家推進、離線靜止**：單機文字遊戲沒有理由懲罰關掉分頁的人。
2. **八段固定順序、帳本集中在第 6 段**：所有失敗政策在一處明示，測試斷言也只看一處。
3. **事件待選時暫停 tick 而非跳過**：BB 式事件要有份量，跳過會讓選項形同虛設。
4. **跨多日逐日補算**：等七天與連按七次「等一天」結果必須一樣，否則玩家會學到奇怪的技巧。
5. **破產終局綁催收事件鏈、不是數字一到就結束**：給「最後一搏」的空間，也讓白手套有登場理由。
