# 使用者試玩回饋（2026-10-24，頂層轉交原文）

[lead-ui-fix 契約](contract.md)｜[REPORT](REPORT.md)

使用者說配色 OK，操作手感問題很多。逐項：

1. **敵人部件血量**：敵人在視野內 → 看得到全部部件與每層血量；離開視野 → 顯示最後所見、灰色標示。（目前 viewmodel 的 SPEC-GAP 只給層血量。若規則層知識模型不給，從 session 的觀測補，不改規則。）
2. **行動流程**：棋子行動後保持選取並直接浮出下一步選單（攻擊／能力／待機），不用回頭再點；行動點用完自動待機並跳到下一台可行動的我方；「結束回合」隨時可按、不需先選棋子，未行動者視為待機；若還有未行動的機體，先提示「還有 N 台未行動，確定結束？」，再按一次 E 確認。
3. **戰場面板隨戰場大小縮放**：小地圖格子放大填滿面板、不留大空白；大地圖格子縮到可讀下限後才捲動；視窗縮放時重算。這是預設初始格大小。
4. **戰場可手動縮放**：Ctrl＋滾輪、+／− 鍵、面板角落縮放鈕；以游標／滑鼠所在格為中心縮放；記住設定（localStorage，包 try/catch）。原滾輪捲動保留。
5. **行動中棋子高亮**：粗框或呼吸閃爍，與「選取中」不同色；敵方回合也高亮當前行動的敵機並鏡頭跟過去；可移動範圍、攻擊範圍用不同底色標出。
6. **所有行動在戰場上演出**，不只戰鬥記錄：移動**不要一格一格走**——棋子直接到終點，起點到終點閃一下路徑箭頭約半秒淡出；攻擊畫攻擊線、命中格閃、浮出傷害數字與部位（如「左臂 −12」）或「未命中」；效果／狀態（過熱、暴走、部件損毀）在棋子上跳短標籤；敵方回合逐步播放（動作間停頓）；點戰鬥記錄某行，鏡頭跳到該位置。
7. **動畫可跳過**：畫面上有「跳過」按鈕（快捷鍵 Esc 或空白）直接跳到結果；設定「動畫：開／快／關」並記住；關時只剩終點路徑閃與傷害數字。
8. **操作按鈕面板持續存在**：不因未選棋子、敵方回合、捲動或縮放而消失或移位，固定在畫面一側；不能按的按鈕變灰，tooltip 寫原因（「敵方回合中」「尚未選擇棋子」）。
9. **已知粗糙處**：可選要打哪個部位（目前自動選第一個合法部位）；層種類顯示中文名（從內容包取名稱，沒有就建 UI 用對照表，不在程式寫死內容 id 以外的東西）。

所有新增操作都配快捷鍵並寫進 keymap.json 與說明表。
