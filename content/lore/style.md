# style — 《蝕潮獵團》風格與用語（太空歌劇版，所有內容線照此寫）

[lore README](README.md)｜裁示原文 `wf/workflows/planning/design-notes/world.md`（2026-10-24 末段：「我不太喜歡硬科幻，我想要的是太空歌劇類型，不要電磁學那套，想想 Warframe 那樣」「就，不要太過現實啦」）

## 總綱

**不要太過現實。敢誇張、敢浪漫、敢中二。** 這個世界的規則靠「說了就是」撐住，不靠物理：十分律不解釋，夢召不解釋，裂縫從哪來不解釋。寫設定與文本時的三條：

1. **意象優先於機制**。一把武器先有名字與畫面（「月弓一引，月壤如雨」），再有數字。數字只出現在型號迭代（II型、V4）與遊戲數值，不出現在世界觀敘述裡（沒有口徑、沒有瓦、沒有公里／秒）。
2. **古代遺產、半肉半鐵、超常力量、華麗招式、勢力史詩**——Warframe 的語感：東西是「長」出來的、「醒」過來的、「認」人的，不是「製造規格」。衍型機也有一點神秘感：工程師看著古代機「就懂了」，不是算出來的。
3. **冷硬潮濕的捕鯨船底色不丟**（見 world spec README 基調），但上面蓋一層神話的光：窮酸的獵團開著漏氣的老船，去拘束一隻會發光的怪獸，而船尾那門砲有自己的名字。黑色幽默與中二並存——角色自己也知道招式名很誇張，照樣吼出來。

## 用語（2026-10-24 改名定案）

使用者定的新詞與改名線的衍生詞定案在 `wf/workflows/planning/design-notes/terms.md` 末段與同目錄 `terms-rename.json`（舊｜新｜英文意涵｜依據，含「不改」清單），全庫已照它換過一輪。寫新內容直接用新詞：

- **古代機**：本體就叫古代機（不叫「殼」，也不縮寫成「古機」），外層叫**裝甲**；獵團黑話叫遺跡「**墟**」、叫裂縫「**蝕**」。學者是**稽古學會**，高原教團是**守寢人**，2089 年那場全人類同夢叫**夢召**，人物屬性**古緣**（對「獸緣」），月背**墟帶**、慶州**古陵**、碎片**骸片**、安放古代機的石室**內殿**、拘束用**鎮釘**。
- **衍型**：衍型機、衍一、衍二、衍式兵器；衍型機的外甲叫**衍甲**；動詞「摹」改用仿／仿造。
- **蝕**：裂縫週期湧現叫**蝕潮**（口語「蝕」），蝕月、蝕錨、蝕壓、蝕訊（預報）、蝕域；蝕潮的強弱起落用潮汐語彙照寫：**大潮**（大潮期出大怪）、小潮、平潮、退潮；教派**沐蝕會**；地月渡輪**渡月船**；先民時代**先蝕文明**。
- **機甲**：**鎧甲**、**靈目**、**矢**（凡鐵矢、光矢…）、**流刃**（流光鍛）／**骨刃**（獸甲削）。

與海洋本義相關的「潮」（潮汐、潮間帶、海獸與海岸地名）、甲殼本義的「殼」（甲殼、地殼、蟲族部位）不改；程式 id（`shellKin`、pool id 等）不動。

## 能量與科技體系：核心名詞

一套取代「電／熱／電磁／彈藥」的風格化稱呼。遊戲資料的 pool id（`heat`、`charge`）不必改，**顯示名與所有敘述文字**用這套。已抽到 [glossary.json](glossary.json)（23 列）。

欄位：`concept` 原概念；`term` 本作用語（粗體的是正式名，斜線後是別稱）；`note` 一句可直接寫進文本的解釋。

骨幹六個詞先記住：**源流**是一切能量的源頭（從裂縫另一端流過來的東西本身，古代機、裂晶、異能都是它的凝態）；**裂晶**是裂獸的心臟、人類燒的能源；**流光**是機甲的血（取代「電能」，汲光＝充能）；**燼**是流光燃過的渣（取代「熱量」，燼滯＝遲緩、燼爆＝部位自損、排燼＝散熱器）；**矢**統稱一切投射物（凡鐵矢／光矢／追矢／拘束矢，不講口徑講「幾矢連吼」）；**機魂**是住在魂核裡的另一個駕駛員。其餘——光幕、鎧甲、靈目、吼砲、弧光、流刃、算核、術式、星哨、天網、浮芯、月弓、渡月船、鐵翼、鐵龜、鍛研、公刻——查表。

## 武器與招式的命名語感

**武器**＝意象詞＋器類：「斷崖吼砲」「雷雞連吼」「弧光矛」「千囊轟」。不帶數字口徑；迭代用型號（「斷崖吼砲-II」）。

**衍型機系列**照 design-notes 三階：D 級代號（「犁」「K-9」）→ A–C 級系列＋型號（「堅盾-II型」「長槍-V4」「燕鷗」）→ 高階愈中二（「幽冥鐵騎-浮屠」「極光」「偷天」），隊長機用「冠名-系列」（「連星-劍魚」）。系列名偏器物、鳥獸、神話；勢力各有一套語感（塞勒涅型錄體＋希臘神話、殘聯軍械庫鳥名、釜山佛教語、基多安地斯神名…）。

**古代機**原始無名，由發現者以神話命名（既有）：夸父、刑天、恩底彌翁、維拉科查、處容、迦梨、恩凱、埃吉爾、赫卡忒……不同勢力可叫同一台不同名。

**招式**：古代異能四到六字、像誓言或咒（「不退之誓」「借傷萬年」）；生物系吼出來的是承擔（「牠先吃我！」）；機魂的招式名由機魂自己取，可以很怪（「請確認償還意願」是手套的催收起手式）。

**稱號**：A 級以上怪獸有二名（「千囊房東」「赤眼兇星」「白夜」），生物系機甲有登記號／小名／凶名（既有）。

## 禁用詞（敘述文本與命名裡不出現；遊戲資料 id 不受限）

硬科幻與現實軍武的詞一律不出現：電磁、電壓、電流、電池、伏特、瓦、焦耳、千瓦、電子、電路、晶片、電腦、程式碼、演算法、量子、奈米、核融合、核分裂、反應爐、口徑、毫米／公厘／mm、彈道學、軌道力學、推進劑、火箭燃料、Δv、公里／秒、聲納。有本作替代詞的照換：雷達→靈目、衛星→星哨、無線電→天網、飛彈→追矢、砲彈／子彈→矢、坦克→鐵龜、戰鬥機→鐵翼、電能→流光、熱量→燼、電弧→弧光、散熱→排燼、拘束彈→拘束矢。

禁的是**概念**，不是字：人名地名裡剛好含同字（伊內絲・瓦曼、奧盧瓦塞伊）不受限。

允許保留：氦／氣囊（老船的窮酸）、地熱（城邦的牆內日常）、「論文」（學界存在，但沒有結論——那四千篇十分律論文是個笑話）。

## 寫人物與勢力時

- 勢力要有史詩：一台藍本古代機、一條研發血統、一場代表性戰役、一次背盟或結盟。
- 機魂的個性是**後期、稀有**的現象：一般機魂照本宣科、沒有鮮明人格；只有 S 級以上（節點開滿、陪伴夠久、或出了事）的機魂才長出口頭禪、怪癖、對某個人的執念——會給招式取名、會記仇、會想回家。lore 裡的傳奇機魂都是這種罕見存在，寫它們時要點明「這很罕見」。
- 怪獸是天氣也是神話：寫牠的二名怎麼來的，而不是寫牠多重。
- 駕駛員會死，死得平淡；但吼出來的那一回合要寫得像歌劇。
