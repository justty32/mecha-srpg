# world-pillars／mechs — 三類機甲、人機關係、機魂、古代機、命名、研發（M1–M11）

[world-pillars 入口](../world-pillars.md)｜裁示原文 [design-notes/mechs](../../planning/design-notes/mechs.md)（無章節錨點，→ 後寫段首粗體標題）｜寫法細則 [mechs](../mechs.md)、[ancient-people](../ancient-people.md)

### M1 三類機甲共用骨架、來源不同：機械製造、生物捕捉改裝、古代遺跡唯一掉落

**為什麼**：「普通機械機甲；生物系機甲（捕捉怪物，配上機械拘束裝置與駕駛艙）；古代機甲（從遺跡挖出，每台獨一無二，性能都是最頂尖）」。
**做**：三類都是「機甲＝裝備、部位有 HP」；機械＝製造／採購，生物＝戰場捕捉＋拘束器與駕駛艙當部件，古代＝遺跡探索、黑市、月面，不可量產、只修不換。
**不做**：量產古代機；古代機換部件；生物系寫成工廠造。
→ mechs「三類機甲」

### M2 人機關係三條：古代機自己選主人、生物系看意志承擔、機械系靠科研靠錢

**為什麼**：使用者「喜歡機器人動畫的熱血橋段」。古代系「機甲自己選擇主人，主人的意志與信念會與其共鳴」；生物系「看重駕駛員意志是否堅韌——要承擔怪獸機甲狂暴的意志，承擔愈多愈能發揮怪獸力量，直到最終突破上限發狂、敵我不分；適合苦大仇深的男主」；機械系「很普通，靠科研、靠錢，吃營運能力」。
**做**：共鳴＝信念比對（`will.beliefs` 對 `resonance.beliefs`），是門檻也是加成；承擔＝可推高的計量，過閾值失控成敵我不分；寫這兩種橋段時要熱血——吼出來的那一回合像歌劇。機械系就是平凡可靠。
**不做**：古代機買來就能開；生物系靠感情馴服；機械系有驚喜或感情（除非給它機魂）。
→ mechs「三類機甲的『人機關係』」

### M3 異系部件要付同樣代價：裝生物件就承擔、裝古代件就共鳴

**為什麼**：機械系「有時會安裝生物部件或古代部件（遺跡挖出來的），裝了之後也要承擔前述那些（意志負荷／共鳴條件）」。
**做**：生物部件填 `burden`、古代部件填 `resonance`；寫進部件說明：不達條件是死金屬或會反咬。
**不做**：異系部件當免費加強；機械系靠拼異系件變成古代機。
→ mechs「三類機甲的『人機關係』」末段

### M4 機魂是人物不是部件：另一個駕駛員，靠科研天賦樹＋陪伴長大

**為什麼**：「AI 就是另一個駕駛員，像『機魂』那樣」；開發選方向「像點天賦樹」，「若駕駛員或科研人員耐心陪伴，自然更好，但花時間」。
**做**：`kind:"soul"`，與人共用人物骨架，成長來源是科研方向＋陪伴；座艙可有人、有機魂、或並存，協作／代駕／爭奪控制是系統；用語「魂核」「術式」「算核」。
**不做**：寫成會講話的排燼器或機甲欄位；寫成「電腦」「程式」；招募機魂——它是育的或租的。
→ mechs「機械系的 AI＝機魂」

### M5 鮮明個性只限 S 級以上的機魂

**為什麼**：「機魂也可以更有個性一點」→ 同日修正：「有個性的機魂應該是很後期的東西了，可能要 S 級以上。」
**做**：一般機魂照本宣科、名字是登錄號或物件名（七號、算盤），traits 0–1；S 級以上（節點開滿、陪伴夠久、出過事）才有口頭禪、怪癖、對某人的執念、替招式取名；lore 寫傳奇機魂（手套、灰、阿鏽…）要點明「這很罕見」。
**不做**：D–A 機魂鬥嘴、撒嬌、有口頭禪；每台摹機的機魂都是角色；「機魂異常」事件寫成個性（那是低鳴、錯置紀錄）。
→ mechs「機魂要更有個性」（含修正）

### M6 古代機獨一無二：神異能力逐台定義、很多不產燼、數量不限死

**為什麼**：「古代系會有各種神異能力，每台獨一無二、各有各的能力，很多都不產生熱量」；「全世界十二台」不採用，「數量開放（遺跡持續產出、黑市、月面都可能出）」。
**做**：每台一到兩招「只有牠會」且改戰場規則的一小塊（叫起屍體、借傷萬年、一格十分律失效）；池自己定義或根本沒有；留一招無共鳴基本攻擊；新古代機要答得出「改了哪條規則、池叫什麼、認哪種人」。
**不做**：固定名單；「更大的砲」當異能；古代機 produces heat 或裝摹式部件；異能可學、可移植。
→ mechs「古代機甲的能力」「古代機甲數量不限死」

### M7 古代機原始無名，名字是人用神話取的，可多名、可改

**為什麼**：「古代系機甲其實沒有名字，但人們會給它取，通常引用神話傳說。」
**做**：各文化神話輪著用（北歐、希臘、埃及、印度、中國、日本、美索不達米亞…）；不同勢力叫法不同寫 lore `aka`；認主或事件可重新命名，命名本身可以是事件。
**不做**：型號式、代號式名字；撞既有 13 台與 lore 九台；一台只能有一個「官方名」。
→ mechs「古代機甲的名字」

### M8 機械系三段命名：D 代號 → A–C 系列＋前後綴 → 高階愈中二；隊長機「冠名-系列」

**為什麼**：「前期是普通代號（如 AK-47），通常 D 級；再來是『系列＋前綴／後綴』（如 堅盾-II型、劍魚-V4）……級別愈高，系列名與前後綴愈中二、魔幻、高大上、酷炫，端看開發此機甲的勢力或個人的喜好（如 幽冥鐵騎-浮屠、極光）」「也有『連星-劍魚』這類：系列普通但多次迭代後弄出一台隊長機」。
**做**：命名風格是勢力的屬性（一勢力一套語感）；參考現實坦克、飛機、戰艦的**命名方式**；寫法統一「-II型」「-V4」。
**不做**：D 級取中二名；Mk2 寫法；名字帶 mm、kW、口徑；隊長機寫成古代機（它仍可量產維修）。
→ mechs「機械系機甲的命名」

### M9 各勢力的研發血統源自它挖到／保有的古代機

**為什麼**：「機甲研發這塊，因為源頭是古代機甲，所以各勢力依據其挖掘出的、保有的古代機甲的不同，其研發的機甲也各有不同特色。」
**做**：每台摹機 tags 帶 `lineage-*`；血統決定部位偏好、慣用池、能力傾向、輪廓與命名語感；同血統彼此像、不同血統差很多；勢力得新古代機開新分支、失去則停滯；lore 勢力必有「藍本古代機與研發路線」節。
**不做**：各家摹機長得一樣；勢力沒有藍本古代機卻有專屬血統；血統與勢力的古代機對不上。
→ mechs「各勢力研發路線源自各自的古代機甲」

### M10 至少一條通用系列（堅盾、長槍）：開源、逆向、流出、分享或年代早

**為什麼**：「至少要有一條通用機甲系列線，也就是一些種類的機甲會因為各種原因，而開源，或被逆向、流出等等，或是單純的分享，或只是時期較早，所以大家都會。」舉例「堅盾系列」「長槍系列」。
**做**：tags `universal`、`exportPolicy:"open"`，各勢力獵團黑市都能造或買；每條通用系列有一句「為什麼大家都會」寫進 lore 事件（公刻、流出）；各家可做本地化改型。
**不做**：每個系列都專屬；通用系列沒有來歷；專屬系列隨便流到市場。
→ mechs「通用機甲系列」

### M11 時間線推進，研發的機型愈來愈多

**為什麼**：「時間線會推進，研發的機甲種類會愈來愈多。」
**做**：`availableFrom`、`requires` 前代、世代演進（一代比一代 HP 多、槽多、名字從型號走向冠名）；新機型節奏受血統、資源、作戰與外交事件影響；內容標「首次登場時間／前置條件」。
**不做**：靜態型錄；2108 開場就把全部機型放進市場；新機型憑空出現沒有前代與事件。
→ mechs「研發隨時間線推進」
