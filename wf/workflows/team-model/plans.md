# 方案與時間軸

本頁由 [`../team-model.md`](../team-model.md) 拆出。

這頁是 **project-owned**——隨每月帳單與錢包變動，**每次改動要標日期**，kernel 升級不會覆蓋它。

現行角色依 2026-10-27 使用者裁示，詳見 [team-model](../team-model.md)；以下替代方式不預設模型性能或帳單效果。

| 角色 | 現在（2026-10-27）| 需替代時 |
|---|---|---|
| 頂層／規劃 | `gpt-6-astra` | 記錄不可用原因與替代模型，規劃與決策職責照舊 |
| 領導／普通工 | `gpt-6.1-sol` | 依任務與可用額度選模型，記錄替代與協調方式 |
| 簡單工作 | `gpt-6.1-terra` | 可選其他可用模型，記錄替代原因，不推論未實測性能 |

agent 可再派子 agent，模型無限制；平行工人最多 3 與重負載限流照舊。原生子 agent 用工具回傳，外部 `codex exec` 線走 inbox。

某一層的模型要消失時（方案到期、漲價、下架），先在這裡寫替代方案與連帶效果，並標日期。
