> **2026-10-23 深夜使用者裁示（覆蓋本提案）**：(1) **相位說不採用**——飛機與戰鬥機可以傷害怪獸，但傷害十分之一，這是世界規則，不解釋；機甲中心主義來自古代遺跡對所有人的「洗腦」與世界規則，最初機甲是遺跡挖出的古代機甲、機械系以其為藍本。(2) **古代遺跡與怪獸同時出現**（簡史的 2089／2097 時序要改）。(3) **「B 級是 C 蛻皮而來」不採用**，怪獸等級不是成長階段。(4) 怪獸有蟲族、獸族、異形、菌絲等多族。(5) **古代機甲不限十二台**，數量開放。(6) 母體／子體與蛻皮**保留為某些族的設定**，不是全體規則。(7) **勢力大大小小、很多**，不限六個。原文見 [design-notes/world](../../design-notes/world.md)；修訂由 spec 線處理，本資料夾暫不改。

這是 Fable 規劃線 `plan-world` 的提案稿：使用者只定了骨架（2108、地球＋月球、三類機甲、裂縫與地盤、SSS–D、營運層），其餘「都隨意」。每個子檔的每一節都標 **使用者裁示／我的提案／理由／放棄的替代案**，方便逐點推翻。戰鬥數值與技術棧不在這裡。

## 一句話設定

**2108 年，月亮每個月把地球的傷口撕開一次；人類靠買來的機器、馴服的怪獸、挖出來的死人機甲，當傭兵活下去。** 工作名《潮獵》。

## 基調

冷硬、潮濕、帶黑色幽默的捕鯨船小說：怪獸是災難也是漁獲，傭兵是消防隊也是屠夫；沒有拯救世界的英雄，只有這個月的薪水、債息與獸欄裡會不會多一隻。文字要短、具體、有氣味；駕駛員會死，死得平淡。環太平洋給了「巨獸與機甲的重量」，Into the Breach 給了「敵方意圖看得見、地圖本身會攻擊你」，Battle Brothers 給了「人比機器貴」。

## 十句話世界簡史

（一）2041 年，月面城市「靜海市」建成，塞勒涅工業的質量驅動器開始把月壤射向地球，地月經濟一體化。（二）2089 年 3 月 14 日「第一次潮」：全球 37 處同時裂開，出來的東西沒有名字，三週內吞掉孟買。（三）2090 年，軍隊學到裂獸的身體一半留在「裏側」——飛彈與戰機會穿過去，慢而重的近身打擊才完全碰得到；機甲從博物館回到戰場。（四）2093 年，各國財政崩潰，防線私有化；第一批獵團由退役機甲師團改組，向城邦收費殺獸。（五）2095 年，第一台生物系機甲「拾號」：一隻被活捉的 C 級裂獸裝上拘束具與駕駛艙，駕駛員活了三個月，牠活了五年。

（六）2097 年，青藏遺跡挖出第一台古代機甲；認主之後，駕駛員開始說一萬年前的語言。（七）2101 年，人類放棄收復孟買、聖保羅、拉哥斯三大蝕域，改畫「蝕線」死守；蝕線以外的地圖從此只有獵團會去。（八）2104 年，塞勒涅封鎖月面遺跡帶，古代機甲的月面來源從此只剩黑市與偷渡。（九）2106 年，殘聯成立：三十一座城邦的鬆散聯合，發契約、發獵牌、不養兵。（十）2108 年，現在：你剛從前任團長的葬禮回來，繼承了一艘漏氦的浮船、三台 D 級機甲與一筆債。
