# world — 2108 地月機甲戰爭：世界觀與營運層構想（第二版提案）

[planning](../../../planning.md)｜裁示原文 [design-notes](../../design-notes.md)

這是 Fable 規劃線的提案稿，第二版（`plan-world-v2`）已套入使用者 2026-10-23 深夜的推翻與補充：第一版的裂獸半身說換成「十分律＋夢召」（2026-10-24 晚十分律再改為「抵抗性＋精粹」）、遺跡與怪獸同一夜出現、怪獸分族（蟲族／獸族／異形／菌絲）、母體繫子體只屬蟲族、蛻皮只屬獸族、古代機甲數量開放、勢力大小不限、機械系 AI 是「機魂」這個人物。每個子檔的每一節都標 **使用者裁示／我的提案／理由／放棄的替代案**，方便逐點推翻。戰鬥數值與技術棧不在這裡。

## 一句話設定

**2108 年，月亮每個月把地球的傷口撕開一次；人類靠仿來的機器、拘束住的怪獸、挖出來的死人機甲，當傭兵活下去。** 工作名《蝕潮獵團》。

## 基調

冷硬、潮濕、帶黑色幽默的捕鯨船小說，上面蓋一層**太空歌劇**的光（2026-10-24 裁示：不要硬科幻、不要電磁學那套、不要太過現實；用語與禁用詞在 `content/lore/style.md`）：怪獸是災難也是漁獲，傭兵是消防隊也是屠夫；沒有拯救世界的英雄，只有這個月的薪水、債息與拘束艙裡會不會多一隻；但船尾那門砲有自己的名字，招式名很誇張也照樣吼出來。文字要短、具體、有氣味；駕駛員會死，死得平淡。環太平洋給了「巨獸與機甲的重量」，Into the Breach 給了「敵方意圖看得見、地圖本身會攻擊你」，Battle Brothers 給了「人比機器貴」。兩條世界鐵律不解釋：**抵抗性**（異次元能量對本次元武器有抵抗性，打得穿的只有精粹；沒有精粹的凡鐵殺不了獸——答「為何需要機甲」）與**夢召**（人類喜歡機甲——答「為何愛機甲」）。傳奇是群像，不指定臉孔（2026-10-24 晚裁示，見 design-notes/world/scale）。

## 十句話世界簡史

（一）2041 年，月面城市「靜海市」建成；2043 年塞勒涅工業的「月弓」開始把月壤射向地球，地月經濟一體化。（二）2089 年 3 月 14 日「第一次蝕潮」：全球 37 處同時裂開，出來的東西沒有名字；同一夜另有 23 處地面塌陷，露出一萬年前的建築——蝕潮與墟同時到來，三週內孟買被吞。（三）2089 年 5 月，人類拿到兩個數字：各國的鐵翼用掉半數庫存，證明舊兵器只刮得動裂獸的外甲、碰不到核——異次元的東西對本次元的武器有**抵抗性**；青藏遺跡裡那台東西醒了、認了一個地質學家（後來人叫它夸父），人類從它學到煉**精粹**的法子，從那一夜起全世界的人都夢見機甲。（四）2091 年，以青藏那台為藍本的第一台機械系「衍一」下線；2093 年各國財政崩潰、防線私有化，第一批獵團由退役機甲師團改組，向城邦收費殺獸。（五）2095 年，第一台生物系機甲「拾號」：一隻被活捉的 C 級掘犬裝上軛與鞍，駕駛員活了三個月，牠活了五年。

（六）2097 年，月面背面裂開一次，同夜露出一條要走好幾天月面車的遺跡帶；塞勒涅三個月內封鎖，古代機甲的月面來源從此只剩黑市與偷渡。（七）2101 年，人類放棄收復孟買、聖保羅、拉哥斯三大蝕域，改畫「蝕線」死守；蝕線以外的地圖從此只有獵團會去。（八）2104 年，靜海市一台衍型機的駕駛員死在座艙裡，它的魂核卻把機甲開回了港——有紀錄以來第一次座艙裡沒有活人、機魂還讓機甲動起來（它怎麼做到的，至今沒人解釋得了）；這是七號，第一個被認為有自己意志的機魂；第一個登錄的機魂是 2101 年的老爹。（九）2106 年，殘聯成立：三十一座城邦的鬆散聯合，發契約、發獵牌、不養兵——它是南亞傘，成立地奈洛比，三十一座是它的創始頂層，不是地球上城邦的總數。（十）2108 年，現在：你剛從前任團長的葬禮回來，繼承了一艘漏氦的浮船、三台 C 級衍型機與一筆債。

## 定案：規模、傘與四期

**使用者裁示（2026-10-24）**：數字 v2「OK」；其餘「就用暫定答案」。以下已定（2026-10-24），含上述機魂首例與殘聯歸屬。

**我的提案**：數字與分區採 [scale-v2](../../design-notes/world/scale-v2.json)。奈洛比、蒙巴薩、三蘭港是同掛南亞傘與撒南傘的雙籤城，大潮夜向誰求援就是政治表態；奈洛比是中立會場，跨傘權責細節仍未定。

十五把傘分三型：中、俄、北美是國家型，以徵召分配、能命令；其餘十把是聯盟型，用評等、競標、席位、獸群、輪守；日、韓是單國小傘，一國即一傘。六種分配機制合為評等、競標、徵召、獸群、席位、輪守；各傘具體事件與讀法維持提案。群島指印尼菲律賓，非洲分南北；傘名暫用描述句，正式命名另走 terms 流程。

四期為崩年 2089–92、碎國 2093–96、築牆 2097–2101、守線 2102–08；人口依序 90→65→55→45→40 億。崩年主因是供應鏈斷；2105–06 年「站穩」指城邦淨損失歸零。北美傘是殘存聯邦改制，唯一仍自稱國家。

**理由**：規模與制度是既有群像的共同基準，歷史首例各有明確口徑。

**放棄的替代案**：殘聯代表全球全部城邦、2104 才首次登錄機魂——與定案相衝。
