# plan-epic REPORT — 十節點八線能否更宏大、更史詩（2026-10-26，Fable 規劃線）

## 結論一句

骨架是夠的（因果鏈接得上、N10 八線全結、天象與產能曲線都接進來了），史詩感被三件事壓住：**前史與崩年沒有節點**（一萬年只有兩行，五十億人的死只有一句框架）、**賭注隨時間縮水**（2089 滅區域文明 → 2108 守一城救三萬人）、**敘述是免責口吻**（每句帶「提案／不預寫」）。大半不必推翻裁示，靠改寫、補兩個節點、加一條線就能把格局撐開。

## 1. 診斷

**時間跨度是空的。** -8900 封蝕、-8850 刻痕，然後一萬年空白。刻痕本身藏著一個現成的史詩謎題——先民封門後五十年還有人刻字，之後無聲——八條線沒有一條用它。先民「輸了上一次蝕潮」付了什麼，無人寫；答案只定成「方法」（怎麼把門推上月亮），沒有「代價」，所以先民是布景不是悲劇，N10 的影像也就少了重量。

**節點分佈偏後。** 十個節點七個落在 2093–2107 這十五年；N01、N02 只隔兩個月；2090–2092 崩年零節點。人口 90→65 億（崩年死二十五億，全程死五十億）只是框架一句；舊世界怎麼死——聖保羅政府解體、江口最後一道徵召令、棄東令、塞勒涅賣救援卻不來——散在年表與 7.7 種子，沒被釘成節點。這是最「平」的一處。

**賭注遞減。** N01 滅區域文明、N05 失一城、N08 守三天救三萬人、「站穩＝淨損失歸零」。數字 v2 其實藏著更大的戲：2089 人類沒有一台機甲就迎了連珠潮；N10 是人類**第一次帶著兩萬四千台機甲、三十台醒著的古代機**迎連珠潮，是兩條產能曲線的正面對決。N10 前因沒有把這句寫成賭注，只寫「某處蝕線崩」。

**敵方沒有線。** 八條全是人的線。對面無臉是裁示、沒問題；但「怪獸也爆產能」只剩一句。三核心裡孟買長出神權城、拉哥斯長出蝕匪邦、桑托斯灣區什麼都沒長；巢母、蛻皮、第一隻被捕的巢母、萬潮葬王那些二名之夜全成孤兒——正因為沒有一條線在記敵方二十年的升級。威脅因此像靜態布景，而不是對手。

**群像沒有反覆出現的「誰」。** 裁示不指定人臉，但史詩需要跨二十年一再出場的角色。現成答案就在手上：古代機。夸父（N02、N03、2100、N10）、迦梨、刑天、恩底彌翁、維拉科查、處容、彩虹蛇、埃吉爾、恩凱——它們會等、會睡、會選、會拒絕，是不違裁示的群像主角，八線卻把它們當資產與藍本來寫。

**反轉全是「讀者知、世界不知」。** 塞勒涅三層知情、迦梨是古代機、沐蝕會全錯卻握真貨，都要到 N10 才一次揭。2097–2107 中段沒有一次公開的、改變所有人方向的反轉。其實 N04 就是：人類的方舟就是門的另一端——「月面也在影像裡壓不住」要到 great-tide 才點出，A、D 敘述把 2097 寫成封鎖與墟帶的後勤。

**制度節點之間缺「夜」。** N03 公刻、N06 協定、N08 獵牌、N09 信貸是四個制度節點；N06 有拉哥斯、N08 有浦那，N03 與 N09 沒有自己的夜。而 2107-04-15 九門同喪（聖馬洛一夜九門皆失，大西洋岸在燒、內海岸在賒帳賣機）已掛 N09，卻只當地理說明。

**母題有、沒接線。** 「兩樣東西一起留下」、「等」、「某地某夜叫出名字」、「線」、「傘」各自孤立。最大的現成鏡像沒被說出來：先民「一個人、一隻獸、一層裝甲」就是今天的生物系機甲加駕駛員——人類正在不知不覺長成等著它的那個東西。其餘鏡像也在：2089 全球同夢 ↔ N10 全球同影像；夸父等二十年 ↔ 刑天沉睡；先民封門 ↔ N10 不知能否重做。

**N10 的收束力。** 強在八線全結、景象已定、五方反應各一句；弱在每線末段都是「待設計／不預寫」，讀起來像佔位。沙盒不能寫結局，但可以寫**不可逆的損失**與**第二時代的問題**：這一夜大潮停戰慣例死了、三種讀法的獨佔同時失效、塞勒涅的祕密再守不住——卻沒有一句把它命名為「所有人第一次看見同一件事的夜」。

**口吻。** 八篇敘述每句帶（提案）（裁示）（不能寫成），是流程產物，但讓歷史讀成免責聲明；史詩感有一半是口吻。

## 2. 建議

### (a) 不動骨架，只加強

- **A1 母題與鏡像表**：history-lines.md 加一節，把上面五組鏡像寫成對照，八線各在對應期點名一次。為何更史詩：讓一萬年與二十年互相押韻。影響：純寫作。成本小。
- **A2 N10 改讀為「同見之夜」（提案名）**：前因加一句賭注（第一次帶機甲迎連珠潮）；後果定三件不可逆（停戰慣例死、三種讀法獨佔失效、塞勒涅祕密守不住）；第二時代的問題寫成「真相公開後誰先動」。影響 A、D、H 末段與 N10 列。成本小。
- **A3 古代機當群像主角**：加一張「哪台古代機在哪個節點醒／睡／選／拒」表；八線敘述改以機為主詞寫它們的二十年。不違「不指定人臉」。成本小。
- **A4 兩個節點補「夜」**：N04 改寫成希望反轉（方舟即門，2097 起人類知道沒有退路）；N09 以九門同喪為它的夜。成本小。
- **A5 沐蝕會寫進 2104 第一次歸還攻勢**：攻孟買＝攻聖城，是第一次人為了核心打人；只加在場者，不加事件。影響 F、H、N06→N08。成本小。
- **A6 每線一個「N10 讀的刻度」**：A 抄本湊齊幾片、B 醒著幾台認了幾台、C B 級機數、D 債在誰手、E 登錄魂逃走幾顆、F 站穩比、G 誰破約、H 學會與沐蝕會換過沒。前四十蝕月玩家作為怎麼決定哪洲先崩，從此有答案；沙盒相容。成本中（線層定義小、引擎後續另算）。
- **A7 史書口吻改寫**：八篇敘述改成世界自己講歷史的口吻，提案／裁示標籤移進 json 腳註欄。成本中（codex polish 批次），排最後。

### (b) 新增或合併節點／線

- **B1 崩年節點「國家之死」（提案名，2090–2092）**：聖保羅政府解體是第一個消亡的國家、江口徵召是最後一道國家命令、棄東令、塞勒涅賣救援不來。G（傘＝國家的鬼魂）、F（第二核心）、D（罪責起點）、C（鐵翼燒光冷戰軍火）在此打結。為何更史詩：五十億人的死有了一夜。成本中：節點表加一列、年表約十條改掛、八線崩年段各補一段。
- **B2 第九條線「蝕域線」（提案名）**：敵方二十年升級——三核心內部長什麼、巢母首見到首捕、蛻皮、萬潮葬王；桑托斯灣區核心留一個「長出什麼」待定。孤兒維持填充層不硬掛（照 2026-10-25 裁示），只是以後有架可放。成本中。
- **B3 前史節點「刻痕停止」（提案名，-8850）**：先民封門後五十年的守線與無聲；只定代價形狀、不定方法（見 C1）。成本小中。
- **B4 地平線節點「門的另一端」（提案名，不定日期、N10 之後）**：月面背面兩百公里墟帶、永眠的恩底彌翁、暗面——給第二時代一個遠方，不是結局。成本小。

### (c) 需請使用者重議的裁示

- **C1「答案內容留白」**→ 允許定「先民付了什麼」的形狀（例：他們把自己留進裝甲，所以墟是空的、機在等），方法仍留白。代價：留白縮小一圈；好處：N10 影像有重量、A3 的機有來歷。
- **C2「S 領主掛旗」**→ 把第一隻領主級的露面排在第 40 蝕月（展現過的最強仍是 S，不違）。代價：定了一個旗；好處：敵方在 N10 第一次有「形」而不是臉。
- **C3「對面無臉」**：**不建議重議**，列出只為說明它是史詩感的上限之一；B2 與 C2 是不碰它的替代。
- **C4 history-lines 的「不新增人名、事件、專名」**：B1–B4 需使用者點頭放寬到節點層（只加節點與線，不加人名）。

## 3. 推薦組合（先後）

1. **A1＋A2＋A4**——純改寫，先把鏡像、賭注與兩個「夜」寫出來，成本最小、效果最直接。
2. **A3＋C1**——古代機當群像主角，順便問一題先民代價；兩件合起來才有「等了一萬年的角色」。
3. **B1**——崩年節點，補最平的那四年。
4. **B2**——蝕域線，讓對手有二十年；順手定桑托斯灣區核心。
5. **A7**——結構定了再改口吻；A6 另走引擎線。

## 4. 請使用者拍板

1. 先民付了什麼——可以定形狀嗎（例：人進了裝甲）？還是連這個也留白？
2. 崩年加一個「國家之死」節點，要嗎？釘在 2090 聖保羅解體，還是 2091？
3. 第九條線寫怪獸與蝕域的二十年，要嗎？桑托斯灣區核心裡要長出東西嗎？
4. 第一隻 S 領主在第 40 蝕月露面，要嗎？
5. 古代機當群像的反覆面孔（不是人臉），可以嗎？
6. N10 定名「同見之夜」（提案名）、定三件不可逆，要嗎？
7. 第 40 蝕月之後給一個不定日期的遠方節點（門的另一端），要嗎？
8. 八篇敘述改史書口吻、標籤移進資料檔，要嗎？

## 使用者裁示（2026-10-26）

原話：「一萬年前的事情不用說太多，保持神祕感。古代機也不用當主角，那是高高在上的，特殊地位的。硬要當主角的話，挑一臺就好，去演繹傳統日本超級機器人那種，但是要融入我們的敘事基調。崩年50億人...這太簡略了，當然可以寫這樣簡略，但是後續的一整個影響，必然是超級大的，這個非常重要。」

頂層讀法：
- 前史維持神祕：C1（先民代價定形狀）、B3（刻痕停止節點）不採；鏡像表 A1 不得藉此展開前史。
- 古代機維持高高在上的特殊地位：A3（古代機當群像主角）不採；可選**一台**承擔傳統超級機器人式的主角演繹，須融入本作敘事基調。
- 崩年死亡可以簡寫，但**其後續影響必須極大、貫穿全部主線**——列為最重要。B1「國家之死」方向保留。
- 第 2–4、6–8 題未答，待 v2 規劃一併重提。
