# world — 2108 地月機甲戰爭：世界觀與營運層構想（第一版提案）

[planning](../../../planning.md)｜裁示原文 [design-notes](../../design-notes.md)

這是 Fable 規劃線 `plan-world` 的提案稿：使用者只定了骨架（2108、地球＋月球、三類機甲、裂縫與地盤、SSS–D、營運層），其餘「都隨意」。每個子檔的每一節都標 **使用者裁示／我的提案／理由／放棄的替代案**，方便逐點推翻。戰鬥數值與技術棧不在這裡。

## 一句話設定

**2108 年，月亮每個月把地球的傷口撕開一次；人類靠買來的機器、馴服的怪獸、挖出來的死人機甲，當傭兵活下去。** 工作名《潮獵》。

## 基調

冷硬、潮濕、帶黑色幽默的捕鯨船小說：怪獸是災難也是漁獲，傭兵是消防隊也是屠夫；沒有拯救世界的英雄，只有這個月的薪水、債息與獸欄裡會不會多一隻。文字要短、具體、有氣味；駕駛員會死，死得平淡。環太平洋給了「巨獸與機甲的重量」，Into the Breach 給了「敵方意圖看得見、地圖本身會攻擊你」，Battle Brothers 給了「人比機器貴」。

## 十句話世界簡史

1. 2041 年，月面城市「靜海市」建成，塞勒涅工業的質量驅動器開始把月壤射向地球，地月經濟一體化。
2. 2089 年 3 月 14 日「第一次潮」：全球 37 處同時裂開，出來的東西沒有名字，三週內吞掉孟買。
3. 2090 年，軍隊學到裂獸的身體一半留在「裏側」——飛彈與戰機會穿過去，慢而重的近身打擊才完全碰得到；機甲從博物館回到戰場。
4. 2093 年，各國財政崩潰，防線私有化；第一批獵團由退役機甲師團改組，向城邦收費殺獸。
5. 2095 年，第一台生物系機甲「拾號」：一隻被活捉的 C 級裂獸裝上拘束具與駕駛艙，駕駛員活了三個月，牠活了五年。
6. 2097 年，青藏遺跡挖出第一台古代機甲；認主之後，駕駛員開始說一萬年前的語言。
7. 2101 年，四隻 SS 被命名為「四天王」，人類放棄收復牠們的地盤，改畫「蝕線」死守。
8. 2104 年，塞勒涅在靜海市地底挖到被當成遺跡的第五隻——還在睡；消息封鎖至今。
9. 2106 年，殘聯成立：三十一座城邦的鬆散聯合，發契約、發獵牌、不養兵。
10. 2108 年，現在：你剛從前任團長的葬禮回來，繼承了一艘漏氦的浮船、三台 D 級機甲與一筆債。
