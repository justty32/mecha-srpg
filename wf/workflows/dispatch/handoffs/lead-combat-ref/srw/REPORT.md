# SRW 參考 REPORT

## 做了什麼
用 WebSearch 查三件事：精神指令、氣力、部位與武器對應。主要來源為 Akurasu 粉絲 wiki 各作品頁。

## 產出
fragment.json 共 8 列（SRW-01 至 SRW-08）：精神指令 2、氣力 2、武器與合體技 2、部位 2。

## 沒做到或證據不足的
- WebFetch 打開頁面兩次都回 502，所有 URL 只在搜尋結果中確認存在，內文細節取自搜尋摘要，未逐頁核對。
- 搜尋結果沒有 Strike（必中）與 Fury（熱血）的 SP 數值，也沒有名為「Evade」的指令；列內 SP 數字僅 Valor 40、Soul 60、Alert 10（EX）。
- 「武器有氣力需求」的泛稱未被證實；確認到的是能力與雙子合體有氣力門檻。SRW-04 的武器氣力欄位來自 Mech Database 欄位描述。
- 氣力增減數值只來自單一作品，各作品不同。
- Gaiden、Operation Extend 的部位破壞未查到；只確認 GC。SRW-08 的 URL 僅是 GC 頁面，用來佐證「其他作品未見」並不嚴謹。
- SRW-02 的來源是搜尋結果中確認存在的頁面，其內文未打開。
