## 評閱怎麼看

自行用瀏覽器 file 開各試作的 `index.html`，不需伺服器或下載；agent 不代開 GUI。SVG 樣張可看：

- 人物：卡茂、薩米爾兩人物日漫風格；髮型、五官、臉型等紙娃娃分件、交叉組裝及完整立繪 fallback。
- 三風格機甲與城市：冷鋼／祕儀／狂潮；城市六層（背景、遠景、中景、前景、動態物件、可互動物件），目前是示意初版。
- 靜海修塢、四地格、射擊／命中／爆炸特效，城市熱點與各層開關。
- 機甲各 9 大層／28 中層，有效葉 142／140／140；檢視父子開關、單看、左右臂連武器及還原可見性。
- JS／CSS 演出：啟動、暫停／續播、還原；換件或配色重建後演出歸零。

## 驗收界線

既有 XML／Node 與離線 PNG 檢查是歷史證據，**不等於真瀏覽器動畫、布局或鍵盤驗收**；待驗：真瀏覽器布局、鍵盤焦點與熱點、樹與換件互動、CSS 動畫時間序列。不能以 agent 看過 PNG 當使用者定稿；SwiftShader 也不代表實體 GPU 效能。任何下載（套件、字型、素材）前先告知項目、來源與用途（[偏好](../wf/workflows/common/user.md)）。
