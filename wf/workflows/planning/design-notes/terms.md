# design-notes／terms — 用語與命名語感

[design-notes 入口](../design-notes.md)｜[planning](../../planning.md)

**「殼」改「原鞘」、「摹」改「衍型」、命名多用「之」「者」（2026-10-24）。** 使用者原話：「『殼』這個，對於中文使用者來說實在陌生，改成『原鞘』吧。然後中文這邊，常常會加上『之』、『者』，比如原鞘之守這種命名。然後『摹』也不常用，改成『衍型』。」頂層提出對照表、使用者回「可以，就這樣」：

| 舊 | 新 |
|---|---|
| 殼（古代機本體） | ~~原鞘~~ → **古代機**（不另取專名；如潮衣殼→潮衣） |
| 殼學會 | 原鞘學會 |
| 殼守 | 守鞘者 |
| 殼訊 | 鞘訊 |
| 殼緣（`shellKin` 中文名） | 鞘緣 |
| 殼帶、殼陵、殼片、挖殼 | 原鞘帶、原鞘陵、原鞘殘片、掘鞘 |
| 殼甲（裝甲層） | 鎧甲 |
| 殼目（感測） | 靈目 |
| 殼矢（彈藥） | 矢（凡鐵矢、光矢…） |
| 摹機 | 衍型機 |
| 摹一、摹二 | 衍一、衍二 |
| 摹式兵器 | 衍式兵器 |

含意：只改顯示文字與敘述，程式識別字（id、`shellKin` 等）不動；命名語感鼓勵「之」「者」（原鞘之守、潮衣之子、斷臂者、守鞘者）。其他 design-notes 子檔保留使用者當時原話中的舊詞，以本檔為準。

**避免英文直譯感（2026-10-24）。** 使用者原話：「因為你們都主要是以英文材料訓練出的模型，對於中文的一些文法語法不太熟，很多都能明顯看出來，都是直接翻譯過來的。比如 shell 就很自然，但殼很明顯就是直譯……中文通常會稍微修飾一下，變成原鞘。」含意：中文命名與文案要以中文母語語感為準——不逐字對譯英文概念，而是加修飾、取意象、用常見構詞（雙字詞、「之」「者」、典故感），讀起來像中文原創；寫完自問「這是不是英文詞換成漢字」。這條適用所有名詞、招式名、地名與敘述文字，是潤飾工作的首要標準。

**音譯式專有名詞也歡迎（2026-10-24，接上段）。** 使用者原話：「不過你們也可以發揮你們英文模型的能力，比如『克拉瑪莎』這種名字，也挺好的。」含意：分兩類處理——**概念詞**（裝備、狀態、資源、組織性質、招式）要中文母語語感、避免直譯；**專有名詞**（人名、機體名、地名、勢力名、古代存在）可以用帶異國感的音譯式名字（如「克拉瑪莎」），要求音節順口、用字雅、不撞常見詞。兩類可混用（例：「克拉瑪莎之誓」）。

**命名流程：先英文（帶拉丁意涵）再意譯（2026-10-24，接上段）。** 使用者原話：「可以先用英文命名，命名的時候可以有一些拉丁文的那種意涵，然後翻譯的時候可以參考這些意涵。」含意：命名分兩步——(1) 先取英文原名，可帶拉丁／古典語根的意涵（例：*Vigil*、*Sanctum*、*Ferrum*、*Aegis*、*Nox*），把「它是什麼、象徵什麼」想清楚；(2) 再依那個意涵做**中文意譯或音譯**，而不是逐字直譯英文（概念詞取意、專有名詞可音譯，見上兩段）。英文原名與其意涵應保留在資料裡（例如 `aka` 或備註欄），方便日後對照與一致化。

**修正：「殼」不另取專名（2026-10-24，接上段）。** 使用者先問「殼」是否改「骸」，頂層說明「殼」有兩種用法後，使用者定：「直接叫古代機吧。第一種改叫裝甲。」——(1) 古代機**外層**（「披上一層不知成分的殼」）→ **裝甲**；(2) 古代機**本體**不再用「殼／原鞘」等專名，**直接叫古代機**（潮衣殼→潮衣、挖殼→掘出古代機）。上表中以「原鞘」「鞘」組成的衍生詞（原鞘學會、守鞘者、鞘訊、鞘緣、原鞘帶…）**作廢待重擬**：改名線依「先英文帶拉丁意涵再意譯」流程與 agy 審查重擬一版，交使用者過目後定案。摹→衍型、殼甲→鎧甲、殼目→靈目、殼矢→矢不受影響（仍待使用者過目整批翻譯腔重審）。

**「潮」改「蝕」（2026-10-24）。** 使用者：「潮」太容易聯想到海洋，機甲科幻題材應更科幻，可在「潮」的基礎上加修飾；頂層提四案（蝕潮、界潮、虛潮、星潮），使用者定：「那就蝕，這強調了本質上，這是異次元對本次元的侵蝕之戰。」含意：世界觀核心＝**異次元（裏側）對本次元的侵蝕之戰**。裂縫的週期湧現稱「**蝕潮**」（口語「蝕」），與既有「蝕域」同源。對照（衍生詞仍經改名線與 agy 審查後交使用者定案）：潮（裂縫）→蝕潮／蝕；第一次潮→第一次蝕潮；潮月→蝕月；大潮／小潮→蝕盛／蝕歇（口語可留大潮小潮待審）；潮錨→蝕錨；潮壓→蝕壓；潮信會→待重擬；蝕域不變；工作名《潮獵》→待定（候選《蝕潮獵團》《蝕獵》）。地名、物名中與海洋本義相關的「潮」（潮間帶、潮汐地形）不在此列，由改名線逐一判斷。

**衍生詞授權改名線定案（2026-10-24）。** 使用者：「衍生詞都按照建議。」含意：上兩段標「待重擬／待定／交使用者定案」的衍生詞，一律採建議版、不再回頭交使用者——已有建議的直接用（大潮／小潮→蝕盛／蝕歇；工作名取第一候選《蝕潮獵團》）；尚無建議的（原鞘系作廢詞、潮信會）由改名線依「先英文帶拉丁意涵再意譯」流程擬一版、經 agy 審查後取其推薦版直接定案，定案表回寫本檔。翻譯腔重審（摹→衍型、鎧甲／靈目／矢等）同樣照建議執行。

**改名線定案表（2026-10-24，lead-rename）。** 依上段授權，原鞘系作廢詞與潮信會等照「先英文帶拉丁意涵再意譯」擬版，經 `agy`（gemini-4-argon-high）兩輪純文字審查後取其推薦版定案；連同前段已定的詞、專有名詞的改法與「不改」清單，已抽到 [terms-rename.json](terms-rename.json)（69 列）。欄位：`類別`（古代機／機甲／蝕／專有名詞／保留）、`舊`、`新`、`英文原名與意涵`、`依據`（使用者定案／agy 第 1、2 輪推薦／改名線依規則推得／改名線判斷）、`備註`。骨幹：殼學會→**稽古學會**、殼守→**守寢人**、殼訊→**夢召**、殼緣→**古緣**、遺跡黑話殼→**墟**（殼帶→墟帶、挖殼→掘墟）、殼陵→**古陵**、殼片→**骸片**、殼室→**內殿**、殼釘→**鎮釘**、摹殼→**衍甲**、殼刃→**骨刃**、潮刃→**流刃**、源潮→**源流**、潮信會→**沐蝕會**、潮訊→**蝕訊**、渡潮船→**渡月船**、前潮文明→**先蝕文明**；「古代機」不縮寫成「古機」（agy：與「古蹟」同音）。**大潮／小潮／平潮／退潮照用**（見下段）。與海洋本義相關的「潮」與甲殼本義的「殼」保留，清單見 json 的「保留」列。

**大潮／小潮保留，用潮汐形容蝕潮（2026-10-24，覆蓋上文「蝕盛／蝕歇」）。** 使用者：「直接用潮汐來形容吧：大潮，小潮，退潮……浪潮有大有小，大潮期會有大怪。」含意：「蝕潮」是名詞本體，強弱與起落用潮汐語彙形容——**大潮**（大潮期出大怪）、**小潮**、**退潮**等照用，不另造「蝕盛／蝕歇」這類專名。這類潮汐形容詞不算「潮」舊詞，改名時不換。
