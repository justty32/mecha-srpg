## 結論一句

崩年不該是一個節點，而是**所有節點的底色**：2108 的每一件事——傘、獵團、信貸、公刻、不老的駕駛員、機魂算裝備、歸還黨、連招式名文化——都能寫成「崩年前是 X，二十五億人死後變成 Y」。本檔先立 X（第 0 節），再逐條寫 Y（第 1 節），然後挑處容做唯一一台超級機器人式的古代機（第 2 節），把前史說多了的地方收回（第 3 節）。

## 0. 崩年前的世界（約 2029–2089-03）——基線

既有材料對這六十年只有六條年表、一篇 era 與 7.9 簡筆；下面先抄既有，缺的補提案。**先民前史不在這裡展開**（見第 3 節）。

**國家格局與秩序（既有 7.9）。** 地緣板塊照 2020 年代延續，冷戰 2.0 從沒打熱、軍備卻堆到 2080 年代——鐵翼、鐵龜、追矢庫存龐大，全是凡鐵。國家在地面仍完整：有稅、有軍、有邊界、有徵召權。但 2077 哨所中立宣言是國家從軌道退場的日子，從此地月之間只剩一家公司。提案補：各國財政早已靠債撐，撐得住靠的是全球長鏈經濟仍在轉；這是為什麼 2089 到 2093 只要四年國家就斷。

**人口九十億的分布（已定總數；分布為提案）。** 亞洲過半、非洲增長最快；最關鍵的一條是**六成人住在離海岸一百公里內**的巨型城市帶——這一句決定了崩年死誰：蝕線＝海岸線，所以蝕潮打中的正是人最密、鏈最長、自己種不出一口糧的地方。注意既有 `content/lore/eras/old-world.json` 寫「六十億人」，與已定的 90 億衝突，建議改（填充層小修）。

**經濟與供應鏈（既有 7.9＋提案）。** 全球化長鏈：港口與鐵路是命脈，糧、藥、零件跨洲走。地球工業吃月壤的便宜質量，國家對公司失去槓桿；塞勒涅賣月壤、信貸與渡輪票，是地月經濟的帳房。提案補：舊世界的效率邏輯是「遠而便宜」勝過「近而貴」——崩年把這個邏輯整個翻過來。

**科技水準（既有）。** 月面有四十萬人的靜海市、月弓、三天到月的定班渡月船、軌道上的星哨網。地面有外骨骼、工程機、走兩步就倒的雙足試驗品；「機甲」是孩子畫在作業簿背面的東西。AI 是按規則行事的傳統 AI，遙控與自動化在工業裡普遍。提案補：戰場無人化受條約與輿論限制、人仍坐在鐵翼座艙裡，所以 2089 燒掉的是人駕的鐵翼，2098 白手套原型也還是人駕——「把人抽出座艙」是塞勒涅戰後才走的路。沒有精粹、沒有抵抗性這個詞。

**城市化與日常（既有 era＋提案）。** 巨型城市、斷斷續續的小戰爭、月亮是移民夢（礦工、工程師、逃稅的、想看地球升起的）。宗教是常規宗教，沒有共享的夢。內陸鄉村空心化（提案），年輕人全在沿海——崩年後內陸能承接 28 億野地人口，靠的是那些被嫌棄的空地。

**各方隱患（既有）。** 月面人口在 2089 年初剛跨過約百萬的門檻；2086 丹增的報告寫了格爾木外的異常，引用零；浦那舊天文陣列、的的喀喀、慶州古墳群全有古老得不像話的地質異常，沒人把它們連起來；國家已不在軌道上，運輸在公司手裡。這些在崩年前都不是問題，崩年後每一條都成了主線。

## 1. 崩年的後續影響（最重要）

死亡本身沿既有一句：2089–2092 死二十五億，主因供應鏈斷，獸直接吞城是少數但最被記住的夜。下面十三條每條寫「之前→之後」、機制、在哪些節點與線浮現、玩家感受的形式。

**1.1 誰死了——人口結構。** 之前：金字塔正常。之後：供應鏈斷殺的是**依賴補給的人**——城市裡的老人、病人、嬰幼兒、醫院與監獄裡的人；活下來最多的是 2089 年十到三十歲、走得動、能搶到吃的那一層。所以 2108 的人口是「中間厚、兩頭薄」：三十到五十歲是社會主幹，老人極少（經驗與傳統隨之斷），而 **2089–2092 出生的孩子極少**——2108 年十六到十九歲那層是個洞，正是新駕駛員該進來的年紀。精粹不老再把這個錯位放大：2089 夢召那批開了十九年只老五年，倖存者世代的臉凍在崩年。浮現：N03（活下來且有組織的人就是舊軍人，所以防線私有化成獵團）、N08（獵牌登記年資）、開局 25,000 名駕駛員的瓶頸。玩家：招募池的年齡分布本身是數值（崩年生稀少且貴）；「不老的」老手是搶手資產；船上沒有長者。

**1.2 勞動力與駕駛員來源。** 之前：人過剩、機器貴。之後：兩層反轉——普通人賤（野地 28 億、難民、養裂村），**能驅動核心的人貴到會被勢力搶**；一人一機（24,000 台對 25,000 人）是崩年留下的常數，不是設計巧合。塞勒涅缺駕駛員走向鐵偶、殘聯不養兵只發牌，都是同一件事的兩種答法。浮現：N03、N04→N07（缺人→複製失敗→鐵偶）、N09（以人抵債）。玩家：薪水高過維修；契約條款有人命價（雇主可撤空援）；評等與年資即身價。

**1.3 知識與技術斷層。** 之前：知識在大學、檔案、工程師身上，全在沿海城市。之後：**崩年死的是機構**。2090 衍一聯合其實是「把活著的工程師聚到一座遠離海的高原上」；2093 分家把一半送上月面，地球的知識斷層被公司接走。公刻（2093）的真正動機建議改讀：不只是秦望舒的信念，是**怕知識再死一次**——圖紙公開是知識的保險。「四千篇抵抗性論文沒有結論」也因此不是笑話而是症狀：寫的人在用一個已死的學界的格式。浮現：N02、N03、N04（月面成知識保險庫→蝕訊壟斷）、N08（共用修造冊）。玩家：研發樹有「失傳頁」，C 級以上件要向國家型傘或塞勒涅買；修造冊是公共財；墟出的藍本比黃金貴。

**1.4 糧食與供應鏈。** 之前：遠而便宜。之後：**近而能吃到的才算**。港口鐵路先被放棄，糧藥到不了內陸——這一句就是二十五億。戰後城邦大小由「一夜能守住、一月能餵飽」決定（牆內靠地熱自種），這是 400 城大中小分布的成因。但精粹在海邊、糧在內陸，兩種經濟隔著蝕線，必須有人跨線運——這就是候鳥號這種船存在的理由。浮現：N03（獸核成貨幣）、N05（難民湧阿克拉吃垮糧）、N06（跨線貿易入條文）、N09（落閘之誓：補給逐筆收費）。玩家：補給價跟蝕曆走（大潮前漲後崩）；護糧契約；船上糧與排燼片都是帳。

**1.5 城市與鄉村重分布；空城。** 之前：沿海巨型城市、內陸空心。之後：城往內陸退，守港 180 座是不肯離港的人，內陸 220 座承接野地；牆內與野地是兩種活法不是貧富。提案補一個被漏掉的量級：三大核心之外，**崩年因供應鏈斷而被棄的死城數以百計**——不是蝕域、只是沒人了。提案名「空城」：地圖上第二種遺跡，拆船幫、長槍打撈、養裂村、歸還黨招募都長在那裡。浮現：N01／F 線、N06（蝕線把空城劃在線外或線內）、N08（拆船幫量產的料從哪來）。玩家：空城節點可搜刮、有難民、有法理爭議（見 1.7）。

**1.6 國家→傘（提案節點「國家之死」）。** 之前：主權＝稅、軍、邊界。之後：主權被重新定義為**「大潮夜誰來救我」**；國家死於做不到「一夜之內到」。三型傘是三種死法：國家型沒死全（保住科研與工業，天花板在它手上）；聯盟型是城邦從國家屍體上自組；單國小傘是國家縮成一座島或半島。北美「舊旗」是唯一還自稱國家的鬼。提案節點 **N-崩「國家之死」（2090–2092）**：聖保羅政府解體是第一個；江口徵召令是最後一道國家命令；棄東令、斷鏈夜、塞勒涅賣救援不來。這些在 7.7 已定為填充素材——提案只是把其中二至三則**升為節點的「夜」**，其餘仍留填充（需使用者點頭）。浮現：N03（私有化＝國家把武力賣掉）、N06（到場的是各區代表，傘多半其後才成立——因為國家才剛死完）、N08（殘聯不養兵是聯盟型的體質）、N09（軍售依賴）。玩家：雇主永遠是傘、城邦、獵團，從不是國家；只有國家型能徵召（玩家在中、俄、北美境內可能被徵）；評等就是護照。

**1.7 法律與財產：無主的地、遺產、債。** 之前：產權與債在國家登記簿上。之後：二十五億人的財產無主，而**沒有任何國家活著宣布債務勾銷**，所以舊世界的債成了可買賣的鬼。提案：塞勒涅成為全球貸方的根，不只是築牆放貸，是它在崩年**收購了死人的債與死城的產權**（它是少數還活著的債權人）；2107 信貸協定的「催收權」追的有一部分是舊世界的帳。歸還黨的法理是「我家在孟買」，蝕線協定的「放棄」在法律上等於宣告無主——兩邊都對。十三年沒有共同法，所以 2094 養裂無法可罰，2106 獵牌法是崩年後第一部跨傘法典。浮現：N03、N06、N08、N09。玩家：船債（葬禮後十分鐘的電話）；空城搜刮的「無主物」規則；契約法理（誰有權雇你打誰的地）。

**1.8 家庭、世代、哀悼。** 之前：家庭完整，死人能埋。之後：孤兒多到獵團與城邦民兵成了養父母——「老爹」「鐵姨」這類稱呼普遍（提案讀法：獵團是崩年孤兒的家）。屍體埋不了，所以哀悼變成**點名**：馬尼拉斷鏈夜之後每大潮逐島點名、沒回的島當夜哀——提案把「唱名」定為全球性的哀悼形式（提案名「唱名夜」，不綁地名）。「某地某夜叫出一個名字」的群像單位，本質是哀悼：怪獸的二名是給殺了親人的東西取名。七號 2104 載著死去的駕駛員回港之所以震動全世界，是因為**崩年沒有人回家**。浮現：N05、N07、N10。玩家：既有良知 strain 與 memory；船上葬禮事件；「找回屍體」是一種契約。

**1.9 宗教。** 之前：常規宗教。之後：三種讀法都是「為什麼活下來」的回答。沐蝕會長在難民營裡（信徒散在印度西岸的營地）——宗教是難民營的制度；巫堂那句「趕不走的。我們跳，是為了讓他們睡得著」是舊宗教的新工作：安眠服務；守寢人是「不肯搬家的人」。不老被讀成恩賜。浮現：N02、N06（法律真空→教團統治）、N07（無肉者）、N10。玩家：教團是雇主也是敵；船員有信仰傾向；大潮前夜的事件。

**1.10 文化與語言。** 之前：國名、學名。之後：語言被活下來的人重寫——蝕、墟、漲潮是獵團黑話成了正名；**傘名全是描述句**，正好是「國家死了、新名字還沒想好」的語言狀態（與既有「正式命名另走流程」相容，建議就讓它一直沒想好）。夢召讓全人類愛機甲，招式名文化與二名文化是崩年後的大眾文化。提案：「崩前」成為時間詞，人用它分彼此——崩前人與蝕生。玩家：文案層；NPC 自報「崩前做什麼」。

**1.11 心理：倖存者的世代。** 之前：無。之後：先畫撤退路線再畫進攻路線（伊爾瑟）；不肯退也不肯讓別人留下；大潮前夜失眠；牆內人怕大潮、傘等大潮。提案：崩年留下兩種英雄模型——**守住的**（拉吉夫）與**走出來的**（薩米爾），F 線守線對歸還之爭的心理底層就是這兩種人互不原諒。浮現：F 線全線、N08、H 線。玩家：船員特質（既有前任特質、熒惑躁動）、離團擲骰的來源。

**1.12 經濟：人比機器貴還是賤。** 答：兩層。機甲貴但可量產（五年翻倍）；精粹核不耗損、是永久資產；**能驅動核心的人不可量產**。所以 2108 的「人比機器貴」不是人少，是能用的人少；而野地 28 億普通人賤到可以被當債抵。機魂在法律上算裝備（N08），是這條邏輯的終點：一個真的人被記在資產欄。浮現：N03、N07、N09。玩家：營運數值裡薪水＞維修、核心是不折舊的資產、損失駕駛員比損失機體痛。

**1.13 為何 2108 是這副樣子。** 每條線的開局狀態都是崩年的函數：A 線沒人能證明怎麼關門，因為能讀刻痕的學界死了一半、另一半上了月；B 線古代機被當資產爭，因為它是唯一不折舊的東西；C 線駕駛員永遠是瓶頸，因為那一層人沒生出來；D 線塞勒涅是貸方，因為它買了死人的債；E 線魂算裝備，因為人早就能被記進資產欄；F 線守線對歸還，因為守住的與走出來的互不原諒；G 線傘是分配機，因為主權被重寫成「誰來救我」；H 線三種教義，因為活下來的人需要理由。**建議在 history-lines.md「框架」段加一節「崩年的底色」，把這十三條各一句掛到線上**，比新增十個節點便宜且更貫穿。

## 2. 一台古代機的超級機器人式演繹

**本作基調（從材料歸納）。** 冷硬潮濕、帶黑色幽默的捕鯨船底色，上面蓋太空歌劇的光；沒有拯救世界的英雄，只有這個月的薪水與債息；駕駛員會死、死得平淡；傳奇是群像、某地某夜叫出一個名字；規則靠「說了就是」撐住、不解釋；敢中二——角色自己知道招式名誇張，照樣吼。超級機器人的型態要進來，得過這五關：代價、制度、旁人的眼光、死得平淡、不當全球主角。

**首選：處容（釜山）。** 理由：(1) 它周圍的超級機器人土壤**已經長好**——尹瑞英每招報名、老爹「沒報的不算」、第三刃「第一刃是處容、第二刃是城牆、第三刃是她們」、釜山孩子模仿處容的舞步、研發路線「一刀開一刀收」；不必新造任何人與勢力。(2) 它**不在主線節點上**（只掛 2100 慶州與 2105 斯卡蓋拉克，皆填充層），所以它當主角不會把夸父、刑天、迦梨拖下神壇，也不預決 N10。(3) 它的異能「逐疫之舞」攤開鄰格敵人意圖——本作戰術核心本來就是「敵方意圖看得見」，處容是這條規則的神話版本。(4) 釜山是環太平洋守港城，每個漲潮夜都有獸上岸：天然的「每集一敵」節拍。**備選：刑天。** 兩個現成招式（不退之誓、骸矛——把自己的裝甲擲出去）、玩家側的認主懸念、守三天救三萬人；但它是 N08／N10 的樞紐且沉睡到第 40 蝕月，拿它當超級機器人會預決認主、也會讓最高高在上的那台落到玩家手裡。夸父不建議：它是「高高在上」的範本本身。

**型態與改寫（每項：型態→本作的寫法）。**

- **招式名喊叫** → 在釜山是**會計制度**：老爹的戰報沒報名的擊殺記「無名之擊」不計戰功，殘聯獵牌照戰報記功，所以吼招式名直接關係薪水與評等。旁人眼光：鹽鷗叫他們「那群鹹的」對頭、歐傘獵團覺得可笑；但釜山因此是亞洲最受崇拜的城。中二被制度化，就不違和。
- **合體／變身** → 不做物理合體。「合體」改寫為**三刃合陣**：處容一舞把意圖攤開，第三刃的刀同一回合落下——是戰術隊形，不是機械拼接。「變身」改寫為古代機**自我進化的一階**（等級無上限已定）：刻痕亮起、形態略變，只在大潮之夜、認主深到一個程度才發生，不可逆，且代價落在人身上（河娜的舞步越來越「沒有人教過」、性格趨神性）。一代遊戲內最多一次（提案）。
- **駕駛者與機的羈絆** → 認主是永久的、同傷、離開超過一蝕月就衰弱：**羈絆就是籠**。河娜被推上城主、最想辭職、「一場不用付錢也不用救誰的舞」——熱血來自她每個漲潮前夜仍一個人去跳。
- **每集一敵** → 以蝕曆為集數：每漲潮夜一隻上岸的二名獸（A 級以上才有二名，釜山海口每年也就幾隻），殺了是精粹收成、是釜山的財政。「每集」不是劇情推進，是沙盒裡釜山那一盤的例行節拍（填充層），玩家把船開去才看得到。
- **熱血宣言** → 兩句現成的：開戰前老爹「團長，報名字。」尹瑞英深吸一口氣吼第一招；而宣言的內容不是勝利，是巫堂那句「趕不走的。我們跳，是為了讓他們睡得著」。本作的熱血是**讓人睡得著**。
- **必殺最後一擊** → 處容**不殺**。它只把門打開，刀是第三刃的，河娜從不在戰報簽名。英雄的最後一擊永遠分給群像——這是「不指定臉孔」在超級機器人型態裡的落法。
- **不敗** → 改寫成「還沒輪到」。古代機的傷就是駕駛員的傷；河娜若死，處容睡、帶怨，釜山的第一刃一夜變成一座要看守的墳。這條在文案裡要讓玩家感覺得到（老兵的話、守夜技工的話），不預寫發生。
- **黑色幽默** → 塞勒涅是第三刃的暗中金主、技師把型錄件銘牌磨掉再裝、城主的印章蓋在一張她讀完了的搶古代機文件上。超級機器人的經費來源是它最不想承認的那家公司。

**高高在上如何保持。** 處容不出釜山（離主一蝕月衰弱）、拒殘聯徵調、塞勒涅搶不到；其餘古代機維持原樣：夸父在窩、刑天在地下、迦梨在蝕域、彩虹蛇在未開的紅土下、恩底彌翁永眠——它們在主線上「等、睡、選、拒」，不演。處容是唯一下到人間跳舞的那一台，所以它可以被孩子模仿。N10 那一夜處容也放影像，河娜在影像前跳最後一段——只給一句，不寫結果。

**玩家怎麼接觸。** 玩家不是駕駛者（候鳥號是旁觀與配合）：釜山契約鏈（守港、護航、斯卡蓋拉克後與鹽鷗的對頭戲）；處容出戰的那幾場是戰場事件（友軍單位，逐疫之舞攤開本回合敵方意圖）；河娜與尹瑞英是可反覆出場的地方級面孔（亞洲那一盤，不是全球主角）。引擎上只需要「友軍古代機單位」與「報招式名計功」兩件小事（走 engine-backlog）。

## 3. 前史維持神祕：建議收回或模糊化

現有主線對一萬年前說得剛好的地方多、說多的地方少。建議收回五處：

1. **夸父「追著太陽走、把裂縫推到月亮上」**（kuafu.json、forerunners.json）：這已把「答案的形狀」具體到一台機的個人事蹟。建議改成守寢人的抄本說法、標傳聞，刻痕只畫「追」，不說追到哪。
2. **刑天「守到所有人都下去了」**（xingtian.json）：「下去」暗示先民去了某處。建議改「守到最後」，去處不寫。
3. **forerunners.json 的「沒有工業的文明走到生物系終點」與「四族裂獸在大地上築巢」**：這是在替一萬年前寫社會史。建議刪成一句「刻痕說得很少」。
4. **「先民把門推向海、把答案埋進山」**（A、F 線前史段，提案層）：方向詞太像地圖。建議只保留「蝕從海來、墟在高處」這個現象，不替先民寫意圖。
5. **great-tide 的「看見的人都知道那是先民把門推上月亮的那一幕」**：N10 影像內容本該留白，這句已給了內容。建議改「看見的人都知道那是一萬年前的事，沒有人說得出是哪一件」。

刻痕停止（-8850）、先民代價（C1）照裁示不展開；鏡像表 A1 若做，只用二十年內的鏡像，不拉前史。
